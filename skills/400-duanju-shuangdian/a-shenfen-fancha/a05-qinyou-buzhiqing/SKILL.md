# 亲友不知情 — 家里不知道的那个大佬

## R — 原文 (Reading)

> 全世界知道主角厉害，唯独身边亲友不知情。
>
> — 《400 个爆款短剧剧本爽点》，一、身份反差・隐藏大佬

## I — 方法论骨架 (Interpretation)

主角在外是顶级大佬（战神、首富、神医），但**他的父母、配偶、子女、发小等亲密关系者对此一无所知**——基于日常印象把他当没出息的人：催婚、嫌弃、贬低、让他别吹牛。外部世界对主角的崇拜与亲友对主角的轻视形成**最亲密也最扎心的反差**。

这个桥段的独特之处在于信息差的"隔离墙"是**亲情**：读者知道真相（憋气）、亲友不知道（轻视）、主角选择不解释（往往有苦衷：怕家人担心、受某协议约束、想低调生活）。当真相最终在亲友面前揭晓时，亲缘关系让情绪冲击比陌生人打脸更深——不是"解气"而是"震撼+愧疚+泪点"。

关键手法：**双视角切换**——外部视角反复给主角光环（被崇拜、被跪拜），切回家庭视角立刻被嫌弃；反差越频繁，读者越期待"家里知道的一天"。揭晓场面要设计**情感点**：家人不是被吓到，而是先震惊、再愧疚（想起自己说过的狠话）、最后情感释放。别把家人写成纯反派（那是 c01 家族嘲讽的玩法），本 skill 的核心是"爱但不知情"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 全世界知道，家里不知道
- **问题**: 主角是隐退战神，家里父母以为他在外面打工，天天催他相亲。
- **方法论的使用**: 外部戏给足主角排面（退役仪式、部下敬礼），家庭戏给足轻视（催婚、说他没出息）。
- **结论**: 反差建立在"信息隔离"上，主角的苦衷维持隔离。
- **结果**: 父母偶然看到主角受全城敬仰的场面，当场愣住，家中氛围反转。

### 案例 2: 家人受欺负，主角护短揭晓
- **问题**: 家人被外人欺负时，主角被迫出手/亮身份。
- **方法论的使用**: 用"保护家人"作为揭晓的合理触发器——不是为了炫耀，而是为了守护。
- **结论**: 揭晓动机越无私，情感共鸣越强。
- **结果**: 家人既震撼又心疼，外部视角（欺负者）则被吓退。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 主角设定为"外强内弱（被家人嫌弃）"的经典短剧人设。
2. 需要亲情线与爽点线交织的长线剧情（家庭误会是持续追更钩子）。
3. 设计"家人遇到麻烦→主角暗中摆平→家人不知→最终揭晓"的单元剧结构。
4. 校验剧本：检查亲友视角是否与外部视角反差充足。

### 语言信号 (用户的话里出现这些就应激活)

- "全家人都不知道主角是首富/战神"
- "回家被父母嫌弃没出息"
- "催婚、被看不起"
- "扮猪吃虎回家"
- "family doesn't know the truth"

### 与相邻 skill 的区分

- 与 `c01-jiazufan-dalian` 的区别：c01 的家人是**恶意的**（嘲讽贬低、等着打脸）；本 skill 的家人是**善意的不知情**（嫌弃但出于爱/焦虑），揭晓是情感戏而非解气戏。
- 与 `a02-weifu-bei-diaonan` 的区别：a02 的刁难者是陌生人/服务角色；本 skill 是亲密关系者，情绪深度完全不同。

## E — 可执行步骤 (Execution)

1. **设定主角的外部光环与隐藏理由**
   - 完成标准: 明确主角的真实地位（高）、亲友眼中的形象（低）、以及不告诉家人的合理理由（保护/低调/协议/曾经不被看好）。
2. **建立"外部崇拜 vs 家庭轻视"的双视角节拍**
   - 完成标准: 至少设计 2 组对照场景（外部敬礼 ↔ 家中催婚），让读者频繁感受反差。
3. **安排一次"亲友视角的误会事件"**
   - 完成标准: 亲友因不知情做出轻视/嫌弃/阻拦的具体行为（催婚、说他吹牛、让他别掺和），该行为需可被后续揭晓打脸。
4. **设计揭晓触发器与情感场面**
   - 完成标准: 揭晓由"保护家人"或"外部事件闯入家庭"触发（非炫耀）；揭晓后家人反应按"震惊→愧疚（想起狠话）→情感释放"三拍写；外部视角补充震惊（欺负者吓退）。
   - 判停条件: 若家庭戏份太重影响主线节奏，可将揭晓拆成"半揭晓"（家人知道一部分）分集释放。
5. **校验合理性**
   - 完成标准: 家人轻视的言行符合"爱但不知情"的人设，避免写成纯恶意（恶意请转 c01）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 主角与家人关系淡漠/无家庭设定。
- 需要"家人恶意欺压"的纯打脸戏——那是 c01 的领域。
- 揭晓后仍强行维持"家里不知道"——信息隔离一旦打破必须处理后果。

### 作者在书中警告的失败模式

- **强行降智**: 家人已亲眼看到主角被崇拜，下一集仍当他是废柴。信息隔离被打破后必须让家人知情或给出新的隐瞒理由。
- **无脑装 X**: 主角被家人嫌弃多年却毫无情绪反应（工具人式忍耐）。建议写主角的隐忍细节（躲开话题、深夜独自处理）增强代入。

### 作者的盲点 / 时代局限

- 该套路依赖"家人普遍势利/短视"的设定，可能强化刻板印象；现代语境下建议给家人"合理的关心方式"（如怕他走弯路）而非纯势利。

### 容易混淆的邻近方法论

- 与"施恩遇贵人"(a08) 混淆：a08 是主角帮了别人；本 skill 是家人帮/损了主角——方向相反。
