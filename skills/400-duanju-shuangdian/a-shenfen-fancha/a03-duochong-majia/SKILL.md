# 多重马甲 — 一个主角，N 个传说

## R — 原文 (Reading)

> 多重身份叠加：同时拥有多个赫赫有名的代号，旁人却不知道都是主角一人；
> 幕后大佬，培养一众大人物却被世人嘲笑；死后复活，震撼全场。
>
> — 《400 个爆款短剧剧本爽点》，一、身份反差・隐藏大佬

## I — 方法论骨架 (Interpretation)

主角不是"有一个隐藏身份"，而是**同时拥有多个相互独立、各自赫赫有名的身份/代号**——战神、医圣、黑客之王、财阀掌门……旁人只知道这些名号的存在，却不知道它们是同一个人。

多马甲的威力在于**爽点叠加与信息差最大化**：每揭开一个马甲，之前所有"奇怪"的伏笔（为何这位大佬对此人恭敬、为何他懂医术、为何他有军令）都被一次性回收，且每个马甲都能独立制造一次"全场震惊"。马甲之间还可以互相成就：A 马甲的名号让 B 马甲的登场更可信。

关键手法：马甲不是堆数量，而是**给每个马甲分配一个"专属能力域"和"专属受众"**（战神之名在军方响、医圣之名在医院响），这样揭晓时每个领域的人都各自震惊。马甲揭晓要有**梯度**：先揭小马甲（信息差小），后揭大马甲（信息差大），最后揭"最大底牌"——这样爽感逐级放大而不是一次耗尽。

## A1 — 书中的应用 (Past Application)

### 案例 1: 多个赫赫有名的代号同属一人
- **问题**: 如何让"身份揭晓"反复制造震惊而不重复？
- **方法论的使用**: 主角同时是战神、医圣、财阀掌门；每卷入一个领域，就揭晓一个马甲。
- **结论**: 马甲 = 可重复使用的震惊装置，且每个马甲服务一个剧情域。
- **结果**: 各方势力纷纷震惊，主角在多个领域获得话语权。

### 案例 2: 幕后大佬（马甲的分支形态）
- **问题**: 主角培养的一众大人物功成名就，世人却嘲笑主角本人。
- **方法论的使用**: 被培养者们的成就 = 主角"隐藏功绩"的马甲化表达。
- **结论**: 马甲不一定是"自己当大佬"，也可以是"大佬是我培养的"。
- **结果**: 当被培养者集体对主角俯首时，反差全面引爆（详见 a04）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 长线剧情需要"反复震惊"的钩子，单马甲不够用。
2. 主角需要在多个领域（商、医、武、黑客等）获得影响力。
3. 需要给主角设计"身份谜团"供读者/观众追更（"他到底还有多少身份？"）。
4. 校验剧本：检查马甲之间是否逻辑自洽、揭晓是否有梯度。

### 语言信号 (用户的话里出现这些就应激活)

- "给主角加几个马甲"
- "多重身份设定"
- "战神/医圣/财阀都是同一个人"
- "马甲文怎么写"
- "隐藏身份层层揭晓"
- "multiple identities / alter ego"

### 与相邻 skill 的区分

- 与 `a04-muhou-dalao` 的区别：a04 是"培养大人物"（主角在幕后操控他人）；本 skill 是"自己拥有多个名号"（主角自己就是多个大佬）。
- 与 `a05-qinyou-buzhiqing` 的区别：a05 强调"亲友不知道"，本 skill 强调"所有马甲同属一人"的信息差结构，可组合使用。

## E — 可执行步骤 (Execution)

1. **盘点主角能力域，规划马甲数量**
   - 完成标准: 按主角的能力列出 2–4 个独立领域（武、医、商、信息、权……），每个马甲绑定一个领域；数量不宜过多（≤4 个核心马甲），避免失控。
2. **为每个马甲设计"名号 + 专属受众 + 专属信物/特征"**
   - 完成标准: 每个马甲有独立代号、至少一个"领域内被敬畏"的场景、一个可被辨认的特征（令牌/医术/剑法）。
3. **设定马甲间的信息隔离规则**
   - 完成标准: 明确哪些角色知道哪些马甲（信息差表格），防止"全世界都知道"导致马甲失效；亲友知道的马甲单独规划（配合 a05）。
4. **编排揭晓梯度**
   - 完成标准: 按"小马甲 → 中马甲 → 底牌"排序揭晓；每次揭晓都应有独立的高潮点与回收的伏笔；单集只揭 1 个核心马甲。
   - 判停条件: 若剧情接近尾声，可设计"所有马甲同时揭晓"的总爆发，但此前必须完成全部伏笔铺设。
5. **校验逻辑自洽与降智风险**
   - 完成标准: 检查每个马甲的揭晓是否由剧情因果驱动（非强行巧合）；马甲设定表是否经得起读者追问（"他怎么可能同时是……"）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 短篇/单集剧本：马甲需要长线铺设，篇幅不够会显得草率。
- 主角定位为"普通人成长"的题材：马甲流与"从零成长"的弧线冲突。
- 严肃正剧：过多巧合身份会破坏可信度。

### 作者在书中警告的失败模式

- **强行降智**: 全世界都知道"战神=医圣=主角"后，配角仍不知道——必须保持信息隔离规则的真实性。
- **无脑装 X**: 马甲只是用来堆地位、不服务于剧情冲突，会变成"设定自嗨"。每个马甲都应承担一个剧情功能（救人、压敌、揭真相）。

### 作者的盲点 / 时代局限

- 马甲流高度依赖"信息差"，在信息高度透明的现代都市题材中需要更谨慎的理由（隐姓埋名的动机）；玄幻/古代题材天然兼容。

### 容易混淆的邻近方法论

- 与"幕后大佬"(a04) 混淆：马甲是"同一人的多个身份"，幕后是"同一人的多个门生"。
- 与"迪化流"(d01) 混淆：马甲是真实身份结构，迪化是他人脑补——马甲揭晓是真的，迪化的震惊是脑补出来的。
