# 系统加持伪装实力 — 假面板，真底牌

## R — 原文 (Reading)

> 系统加持伪装实力。
>
> — 《400 个爆款短剧剧本爽点》，一、身份反差・隐藏大佬

## I — 方法论骨架 (Interpretation)

主角借助**系统**（或类似的外挂载体）营造出远超实际的实力/身份形象——系统面板显示惊人数值、提供伪装功能（模拟气息、生成假身份信息、制造特效）、发布"唬人"的任务。别人看到主角"深不可测"，实际主角的真实实力可能很弱或仍在成长中。

这个桥段的张力来自"**假 vs 真**"的博弈：主角靠系统**唬人**（装强），但**底牌必须是真的**（至少有一项真实能力/资源可兑现）——否则穿帮时全线崩溃。系统伪装是"虚张声势"(b04) 的系统流变体：b04 靠演技与心理误导，系统流靠"系统这个可量化的外挂"来加持伪装，伪装更"硬"（有面板、有特效、可查询），但穿帮风险也更具体（面板造假会被验证）。

关键手法：**给伪装设置"可兑现的底牌"**（主角真实掌握至少一项能力/资源，关键时刻能兑现）；**给系统设置"代价/风险"**（伪装功能有冷却、有消耗、有被识破的条件）；穿帮与反穿帮（有人验证面板 → 主角用真本事圆场）是本桥段的核心冲突。落点：主角从"靠伪装"逐步走向"配得上伪装"（成长弧线）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 系统加持伪装实力
- **问题**: 主角实力不足，如何让敌人/众人不敢轻举妄动？
- **方法论的使用**: 系统提供伪装功能（模拟强者气息/生成惊人面板/制造威慑特效），主角靠系统唬住对方。
- **结论**: 系统伪装 = 硬核版虚张声势，唬人更可信。
- **结果**: 对手被唬住退让/试探，主角争取到成长时间。

### 案例 2: 有底牌兜底（结构关键）
- **问题**: 伪装被识破怎么办？
- **方法论的使用**: 主角真实掌握至少一项可兑现的能力/资源，伪装被质疑时用真本事圆场。
- **结论**: "假面板 + 真底牌"才是安全结构。
- **结果**: 验证者被真本事镇住，伪装反而升级为"深不可测"（真真假假分不清）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 系统流/金手指流世界观：需要"系统功能"的多样性（不只给真实力，也可给伪装）。
2. 主角实力成长期：需要"唬住对手争取时间"的桥段。
3. 需要"身份/实力迷雾"设定的剧情（别人看不透主角）。
4. 校验剧本：检查系统功能设计是否缺少"伪装类"玩法、以及伪装是否有底牌兜底。

### 语言信号 (用户的话里出现这些就应激活)

- "系统伪装"
- "系统面板唬人"
- "主角实际很弱但靠系统装强"
- "假实力"
- "system bluff / fake power panel"

### 与相邻 skill 的区分

- 与 `b05-jinzhishou-ziyuan` 的区别：b05 是系统/金手指提供**真实**实力；本 skill 是系统提供**虚假**形象（伪装）——一个真给力，一个给"看起来有力"。
- 与 `b04-xuzhang-shengshi` 的区别：b04 是纯演技/心理误导（无系统）；本 skill 是系统加持的"硬伪装"（有面板/特效）——b04 是软唬人，本 skill 是硬唬人。

## E — 可执行步骤 (Execution)

1. **设计系统的伪装功能与边界**
   - 完成标准: 明确系统伪装功能（面板数值/气息模拟/身份伪造/威慑特效）及其代价（冷却/消耗/被识破的条件），伪装必须有边界。
2. **设定"可兑现的真底牌"**
   - 完成标准: 主角真实掌握至少 1 项可兑现的能力/资源（一项真本事/一个真靠山/一件真宝物），关键时刻能圆场。
3. **安排首次"唬人"展示**
   - 完成标准: 主角用系统伪装唬住对手/众人（展示面板/释放威慑），对方被唬住或半信半疑；读者知道主角虚实（上帝视角）。
   - 判停条件: 若伪装对象是"验证型"角色（专家/鉴定师），立即设计验证冲突——用真底牌圆场或转移注意，禁止硬撑。
4. **设计穿帮/反穿帮冲突**
   - 完成标准: 至少 1 次"有人要验证主角"的冲突：伪装被质疑 → 主角用真底牌圆场（或付出代价化解）→ 伪装反而升级为深不可测。
5. **落点：成长弧线**
   - 完成标准: 主角逐步从"靠伪装"走向"配得上伪装"（真实实力/资源追上来），为后期"无需伪装"或"伪装与真实一致"做铺垫。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 系统提供真实实力的设定——那是 b05。
- 无系统/无外挂载体的世界观——除非迁移为"人脉/道具/信息"伪装。
- 伪装无底牌兜底且必须长期维持——穿帮是必然，需给主角成长路径。

### 作者在书中警告的失败模式

- **强行降智**: 主角的假面板被顶级强者一眼看穿后，仍坚持伪装（对方已识破）——识破后必须处理（摊牌/跑路/用真本事逆转）。
- **无脑装 X**: 系统伪装零代价、零风险、次次成功——伪装必须有被识破的可能与代价，否则主角不需要成长。

### 作者的盲点 / 时代局限

- "系统流"是网文/短剧特有设定；非系统题材迁移时，可替换为"伪造身份文件/租赁排场/信息伪装"等现实等价物，结构不变。

### 容易混淆的邻近方法论

- 与"虚张声势"(b04) 混淆：分界是"是否有系统/外挂加持"——有硬载体（面板/特效）用本 skill，纯演技/心理误导用 b04。
