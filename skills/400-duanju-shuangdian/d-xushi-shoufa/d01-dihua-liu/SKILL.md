# 迪化流 — 主角越无辜，配角越敬畏

## R — 原文 (Reading)

> 迪化流：配角根据主角普通言行，疯狂脑补高大上动机。
>
> — 《400 个爆款短剧剧本爽点》，一、身份反差・隐藏大佬

## I — 方法论骨架 (Interpretation)

主角做出一个**完全普通的行为**（打个哈欠、随口说句话、随手做了件小事），配角却**疯狂脑补**出高大上的动机——认为主角深不可测、必有深意、是在布局惊天之计。主角自己一脸无辜（甚至不知道发生了什么），配角已经在心里把主角神化了。

迪化流的爽点来自"**解读权错位**"：主角什么都没做，但别人脑补的一切让主角显得无敌。它同时产生**喜剧效果**（主角无语、配角一本正经地脑补）与**敬畏效果**（读者顺着配角的视角觉得主角深不可测）。它是"扮猪吃虎"体系的衍生手法，可叠加在任何隐藏大佬类桥段上。

关键手法：**主角必须真无辜**（这是与"虚张声势"的本质区别——主角没主动误导）；**配角脑补要有"合理钩子"**（主角的某个真实特征：身份背景、气场、过去的传说，让脑补"半真半假"地成立）；**脑补过程要具象化**（配角内心戏：逐层分析、越分析越怕）。落点通常是"配角自我攻略，主动退让/讨好/恐惧"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 一拳超人（经典原型）
- **问题**: 主角实力无敌却不被认可，如何制造反差？
- **方法论的使用**: 配角们根据主角"普通"的外表与日常言行，脑补各种高大上设定（其实是脑补）；主角的普通反应与之形成喜剧反差。
- **结论**: 脑补是"实力不被认可"的喜剧化表达。
- **结果**: 配角敬畏，主角无语，反差持续产生笑点与爽感。

### 案例 2: 配角根据主角普通言行疯狂脑补
- **问题**: 如何让主角"什么都没做"也显得深不可测？
- **方法论的使用**: 主角随手丢了个垃圾/打了个盹，被有心人解读为"测试我/布局警告"。
- **结论**: 解读权在配角手里，主角越无辜效果越强。
- **结果**: 配角自我攻略（主动退让/讨好/恐惧），主角一头雾水。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 需要"喜剧 + 敬畏"双效果的桥段（轻松氛围下的深不可测）。
2. 主角深藏不露，需要让配角"自己吓自己"以衬托主角层次。
3. 需要低成本制造"主角很牛"的认知（脑补比亲自展示更高效）。
4. 校验剧本：检查是否缺少"误读"类手法（全是直接打脸，缺少脑补趣味）。

### 与相邻 skill 的区分

- 与 `b04-xuzhang-shengshi` 的区别：b04 是主角**主动**误导（有策略）；本 skill 是配角**自发**脑补（主角无辜）——主动 vs 被动是核心分界。
- 与 `c05-wuxin-zhi-ju-re-bo` 的区别：c05 是"脑补引发风波"（冲突向）；本 skill 是"脑补产生敬畏"（喜剧/反差向）——同一机制，落点不同。

## E — 可执行步骤 (Execution)

1. **设计主角的普通行为**
   - 完成标准: 主角行为本身普通且无意（打哈欠/随口话/随手小事），有具体场景。
2. **设计脑补的"合理钩子"**
   - 完成标准: 配角脑补有依据——主角的某特征（身份背景/气场/传说/前一行为）让解读"半真半假"成立；脑补完全凭空则显假。
3. **具象化配角脑补过程**
   - 完成标准: 写配角内心戏：逐层分析（"他打哈欠不是困，是觉得我无趣""他刚才那句话是在点我"），越分析越恐惧/敬畏，一本正经。
4. **安排主角的无辜反应**
   - 完成标准: 主角对自己被神化毫不知情（或无语/一头雾水），形成喜剧反差；避免主角主动配合脑补（那会滑向 b04）。
   - 判停条件: 若需要脑补引发冲突剧情（风波、站队），切换/组合 c05；本 skill 保持"敬畏喜剧"落点。
5. **落点：配角自我攻略**
   - 完成标准: 配角因脑补而主动退让/讨好/恐惧/效忠，主角被动受益；脑补内容可为后续揭晓埋钩（主角真实身份揭晓时，脑补与真相形成呼应）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 主角主动误导/演给对手看——那是 b04。
- 需要脑补驱动冲突风波的剧情——那是 c05。
- 严肃正剧：过度夸张的脑补喜剧会破坏基调（除非明确喜剧定位）。

### 作者在书中警告的失败模式

- **强行降智**: 配角脑补的内容毫无依据（主角明显就是个普通人）——需要"合理钩子"让脑补说得通。
- **无脑装 X**: 全剧所有配角都在无脑神化主角（缺乏有脑子的角色质疑）——至少安排 1 个"不信邪"的角色去试探/揭穿，脑补才有戏剧张力。

### 作者的盲点 / 时代局限

- 迪化流依赖"信息不对称 + 脑补文化"（网文读者非常熟悉）；影视化时内心戏需要外化（台词、表情、独白），避免冗长。

### 容易混淆的邻近方法论

- 与"信息差"(d03) 的关系：迪化是信息差的喜剧化应用（配角因信息差而脑补），但迪化强调"脑补过程"本身，信息差强调"错误认知撞上真相"的反转。
