# GLOSSARY.md — 全书共享术语词典

> 由阶段 1 的 glossary 提取整理，是所有 skill 的共享词典。
> 使用方式：任何 skill 在生成/校验桥段时，遇到下列术语须按"作者用法"理解，而非字典义。

## 术语表

| 术语 | 作者的定义（本技能包用法） | 和常识用法的差异 | 关联 skill |
|---|---|---|---|
| **爽点** | 能"快速给读者情绪满足"的情节单位 | ≠ 仅指打架打脸；物质收获、地位提升、他人崇拜、感情收获都是爽点 | 全部 skill（校验维度见 meta-shuangdian-jiaoyan） |
| **扮猪吃虎** | 主角实力/地位极高，但对外表现为小人物，被轻视后揭晓反差 | ≠ 单纯低调；必须包含"被轻视"与"揭晓"两个阶段 | a01–a08 全类 |
| **迪化流** | 配角根据主角普通言行，疯狂脑补高大上动机 | ≠ 主角主动装 X；脑补是配角单方面的，主角往往无辜 | d01-dihua-liu |
| **曝光流** | 主角姿态放低，却做出轰动大事 | ≠ 身份揭晓打脸；不打脸任何人，只展示"低姿态+大结果"的反差 | d02-puguang-liu |
| **信息差** | 利用双方掌握信息的不对称制造冲突与反转 | ≠ 单纯隐瞒；必须在"错误认知撞上真相"时引爆反转 | d03-xinxi-cha（底层引擎，全部 skill 依赖） |
| **打脸 / 当众处刑** | 配角炫耀、欺压、贬低主角，局势反转后配角颜面扫地 | "当众"是核心变量，有目击者才有戏剧张力 | c01–c06 全类 |
| **越级反杀** | 主角硬实力超出对手预期，越级杀敌、绝境反杀 | ≠ 靠运气；核心是"超出预期的赢法" | b01-yueji-fansha |
| **金手指** | 天赋、功法、神器、高人靠山、传说级宝物等资源优势 | ≠ 单纯外挂；强调"资源碾压 + 态度碾压"（宝物随意送） | b05-jinzhishou-ziyuan |
| **马甲（多重身份）** | 主角同时拥有多个赫赫有名的代号，旁人不知是同一人 | ≠ 化名；马甲必须各自"赫赫有名"且相互独立 | a03-duochong-majia |
| **降智** | 作者强行让配角做出不符常理的愚蠢行为，以便主角打脸 | 最典型的写作雷区；校验剧本时的反向检查项 | 全部打脸类 skill 的 B 段 + meta-shuangdian-jiaoyan |
| **扫地僧式** | 扫地、捡垃圾、快递员等不起眼角色实为顶级大佬 | 原型：《天龙八部》扫地僧；职业越卑微，实力反差越大 | a06-saodiseng-shijue |
| **衬托（烘托）** | 用配角行为证明主角实力/地位（预判必败、靠山是手下、代劳） | 主角"不出手也显强"，第三方背书比自吹有效 | b06-peijue-hongtuo |

## 使用注意

1. **爽点**是宽口径术语：校验剧本时按此宽口径盘点，避免只统计战斗/打脸场景。
2. **迪化流 vs 虚张声势 vs 无心之举引风波**三者易混：
   - 迪化流（d01）= 配角自发脑补（主角无辜）→ 敬畏/喜剧落点；
   - 虚张声势（b04）= 主角主动误导（有策略）→ 退敌落点；
   - 无心之举引风波（c05）= 误读引发冲突 → 风波落点。
3. **马甲 vs 幕后大佬**：马甲（a03）是"同一人的多个身份"；幕后大佬（a04）是"主角培养的多个门生"。
4. **炫富被碾压 vs 借势装 X**：前者（c03）资本为真、被更强的碾压；后者（c04）资本为假、被戳穿。
