# 借势装 X 自取其辱 — 虚假资本的崩塌

## R — 原文 (Reading)

> 反派借用不属于自己的资本装 X，自取其辱。
>
> — 《400 个爆款短剧剧本爽点》，三、打脸反转・当众处刑

## I — 方法论骨架 (Interpretation)

反派/配角**借用不属于自己的资本**——别人的名号、财富、权力、关系、成就——到处装 X、狐假虎威，欺压主角或路人。最终，资本真正的主人（或足以戳穿的人）出现，假象当场崩塌，装 X 者自取其辱。

这个桥段的爽点有两层：一是**讽刺的快感**（装 X 者被当众剥掉画皮，虚荣被公开处刑）；二是**正义的清算**（冒名者最终付出代价）。它与"炫富被碾压"(c03) 的区别在于：c03 是"真资本被更强碾压"，本 skill 是"假资本被戳穿"——前者输在"不够强"，后者输在"根本不拥有"。

关键手法：**让装 X 者把假资本"演足"**（借名号、借豪车、借关系，越吹越离谱），**安排戳穿者恰好在场**（资本真主/知情者/能验证的人），**戳穿要当众且彻底**（逐条对质，说过的每句谎都被拆穿）；落点可以是装 X 者当场社死、被资本真主追责。

## A1 — 书中的应用 (Past Application)

### 案例 1: 借用不属于自己的资本装 X
- **问题**: 反派借他人名号欺压主角，如何清算？
- **方法论的使用**: 反派吹嘘自己是某大佬的亲戚/代言人，主角请来真正的资本真主（大佬本人）当场对质。
- **结论**: 假资本最怕真主在场。
- **结果**: 装 X 者当场社死，被真主追责，旁观者看清真相。

### 案例 2: 冒名顶替（变体）
- **问题**: 反派冒充某身份（神医/战神/继承人）招摇撞骗，如何打脸？
- **方法论的使用**: 冒用者撞上真身，或遇到能验证的人，身份当场穿帮。
- **结论**: 冒名者怕"验真"——安排一次权威验真场面。
- **结果**: 冒名者被当场戳穿，信誉尽毁。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 需要"讽刺型打脸"（虚荣/冒名/狐假虎威）的桥段。
2. 反派设定为"靠吹嘘撑场面"的角色，需要安排一次清算。
3. 需要"正义清算"价值观的剧情。
4. 校验剧本：检查打脸戏的类型多样性（本 skill 与 c03/c02 的区别使用）。

### 与相邻 skill 的区分

- 与 `c03-xuanfu-bei-nianya` 的区别：c03 是"真资本被更强碾压"；本 skill 是"假资本被戳穿"——分界是资本真假。
- 与 `b04-xuzhang-shengshi` 的区别：b04 是"主角主动虚张声势吓退对手"（策略，主角掌控）；本 skill 是"配角借资本装 X 被戳穿"（被动，配角社死）。

## E — 可执行步骤 (Execution)

1. **设计装 X 者的假资本与吹嘘行为**
   - 完成标准: 明确装 X 者借用的资本（名号/身份/财富/关系/成就）与其吹嘘的具体行为（欺压、炫耀、招摇）。
2. **让装 X 者把戏演足**
   - 完成标准: 吹嘘戏至少 2 个具体场景（借名号压人、冒身份招摇），让读者积累反感并产生"等着看他穿帮"的期待。
3. **安排戳穿者到场**
   - 完成标准: 戳穿者是资本真主/知情者/能验证的人，其到场有合理剧情驱动（恰好遇上/被请来/主动寻来）。
   - 判停条件: 若无法安排真主到场，可改用"验真"手段（文件、信物、电话核实、专业人士鉴定）。
4. **设计当众且彻底的戳穿**
   - 完成标准: 戳穿过程逐条对质（装 X 者说过的每句谎被拆穿），当场社死；旁观者态度反转。
5. **落点：追责与余韵**
   - 完成标准: 装 X 者承担后果（被真主追责/赔偿/社死/入狱），并给后续留口子（怀恨报复？洗心革面？）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 资本是真的、只是不够强——那是 c03。
- 主角主动借势（策略性虚张声势）——那是 b04。
- 无"可验证"体系的世界观（戳穿缺乏手段）。

### 作者在书中警告的失败模式

- **强行降智**: 装 X 者明知真主会来还继续装——需让装 X 者自信"真主不会来/不认识"（信息差），穿帮才合理。
- **无脑装 X**: 装 X 者毫无理由地得罪所有可能戳穿他的人——保持其"侥幸心理"的合理性。

### 作者的盲点 / 时代局限

- "冒名顶替"在现代题材中涉及法律后果（诈骗、侵权），可往喜剧向（社死）或正剧向（追责）两个方向处理，避免三观问题。

### 容易混淆的邻近方法论

- 与"虚张声势"(b04) 混淆：b04 主角是"掌控者"（主动策略），本 skill 配角是"受害者/小丑"（被动社死）——视角与主动性不同。
