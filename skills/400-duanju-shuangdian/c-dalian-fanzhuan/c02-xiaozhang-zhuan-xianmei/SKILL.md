# 嚣张转谄媚 — 同一张脸的两个极端

## R — 原文 (Reading)

> 配角气焰嚣张找上门，得知主角实力之后立刻谄媚求饶。
>
> — 《400 个爆款短剧剧本爽点》，三、打脸反转・当众处刑

## I — 方法论骨架 (Interpretation)

一个配角**以极度嚣张的姿态**找上门（挑衅、欺压、索要、威胁），读者已经对他产生厌恶；随后他**得知主角的真实实力/身份**，态度瞬间 180° 反转——立刻谄媚、讨好、求饶、认错。

这个桥段的爽点核心是**同一角色的态度剧变**：反转不是换人，而是同一个刚才还在耀武扬威的人瞬间卑微，这种"变脸"本身就是最大看点。读者享受的是"你刚才不是挺狂吗？"的报复快感。

关键手法：**嚣张要演足**（具体动作：拍桌、威胁、羞辱、砸东西），**变脸要剧烈**（求饶方式要具体：跪下、扇自己、称呼变敬语、把责任推给他人），**反差要有观众**（当众变脸羞辱感更强）。变脸之后还要有"余韵"：配角是否真的被放过？主角的处置方式（轻饶/教训/记仇）决定后续剧情走向。

## A1 — 书中的应用 (Past Application)

### 案例 1: 气焰嚣张找上门
- **问题**: 配角上门挑衅，如何制造最大的情绪落差？
- **方法论的使用**: 配角嚣张行为做足（威胁、动手、羞辱），主角不动声色；配角得知真相（主角身份/实力）瞬间变脸求饶。
- **结论**: 先厌恶 → 后爽快，态度反差即爽点。
- **结果**: 配角跪地求饶，旁观者见证变脸全过程。

### 案例 2: 富家公子炫富被碾压（对照）
- **问题**: 配角的气焰建立在什么基础上？如何击碎？
- **方法论的使用**: c03 的炫富是"资本炫耀"，本 skill 的嚣张是"行为挑衅"——都是态度问题，击碎方式不同（炫富靠更好的东西，嚣张靠实力压制）。
- **结论**: 嚣张的资本不同，打脸的方式要匹配。
- **结果**: 无论哪种资本，最终都转为谄媚/求饶。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 需要快速建立"讨厌配角 → 打脸解气"的单集爆点。
2. 主角低调不露相，配角送上门来被打脸（与 a02 微服被刁难配合）。
3. 需要"变脸"喜剧效果的场合（求饶姿态夸张化）。
4. 校验剧本：检查打脸戏是否有"同一角色态度剧变"的反差设计。

### 语言信号 (用户的话里出现这些就应激活)

- "嚣张找上门"
- "知道主角实力后求饶"
- "当场变脸"
- "狗眼看人低"
- "arrogance turns to begging"

### 与相邻 skill 的区分

- 与 `a02-weifu-bei-diaonan` 的区别：a02 是"服务角色/陌生人因信息差刁难"（更多是被动的有眼不识泰山）；本 skill 是"主动上门挑衅的配角"（更主动的恶）。
- 与 `c04-jie-shizhuang-bi` 的区别：c04 是"借用不属于自己的资本装 X"（虚假资本）；本 skill 是"真实嚣张"（可能真有资本，但低估了主角）。

## E — 可执行步骤 (Execution)

1. **设计配角的嚣张资本与挑衅行为**
   - 完成标准: 明确配角嚣张的资本（背景/靠山/实力/金钱）与具体的挑衅行为（上门、威胁、动手、羞辱），行为要具体可恨。
2. **让配角充分表演嚣张**
   - 完成标准: 嚣张戏至少包含 2 个具体动作 + 1 次当众（有旁观者）；主角保持淡定或轻微应对，不立刻亮底牌。
3. **信息引爆：配角得知真相**
   - 完成标准: 真相通过权威信号引爆（主角身份揭晓/强者对主角行礼/主角展示实力），配角瞬间意识到自己惹了谁。
4. **设计剧烈变脸（谄媚求饶）**
   - 完成标准: 变脸要具体：跪下/扇自己/改敬语/推责任/献上好处；求饶分寸符合角色底线（彻底不要脸更喜剧，保留自尊更真实，按剧风选择）。
   - 判停条件: 若配角已知真相仍嚣张，属强行降智，改为信息差仍未引爆（配角不知道），或直接转入战斗/压制（b 类）。
5. **落点：主角的处置与余韵**
   - 完成标准: 明确主角处置（轻饶/教训/记仇），并给后续剧情留口子（配角怀恨再犯？转投主角？），避免"打一次脸就消失"的浪费。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 配角始终不知真相、不产生变脸——那是信息差未引爆的悬疑节奏，非本 skill。
- 主角已公开身份、无人敢嚣张的场合。

### 作者在书中警告的失败模式

- **强行降智**: 配角已看到主角吊打顶级高手，下一场还跑来嚣张——信息暴露后配角必须转变策略（找更大的靠山/暗中报复）。
- **无脑装 X**: 配角只是"为了被打脸而存在"（无动机、无背景）。嚣张需要资本与立场支撑，且变脸后应有后续（不是用完即弃）。

### 作者的盲点 / 时代局限

- 反复"嚣张-变脸"模板会审美疲劳；建议与 c03/c04/a02 轮换使用，且全剧核心"变脸"场面限量。

### 容易混淆的邻近方法论

- 与"借势装 X 自取其辱"(c04) 混淆：c04 的嚣张建立在**假资本**上；本 skill 的嚣张可建立在真资本上但低估主角——分界是"资本真假"。
