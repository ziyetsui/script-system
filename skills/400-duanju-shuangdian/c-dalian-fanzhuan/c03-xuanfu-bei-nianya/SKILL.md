# 炫富炫技被碾压 — 炫耀变成献丑

## R — 原文 (Reading)

> 富家公子哥炫富装 X 被主角碾压；配角炫耀珍藏物件，主角拿出更好的物品。
>
> — 《400 个爆款短剧剧本爽点》，三、打脸反转・当众处刑

## I — 方法论骨架 (Interpretation)

配角主动**炫耀**（财富、地位、藏品、技能、人脉），读者已经反感他的虚荣；主角不动声色，随后**拿出更好的同类东西/更高层次的展示**，当众碾压——配角炫耀什么，主角就赢在什么上，炫耀瞬间变成献丑。

这个桥段的爽点来自"**以彼之道还施彼身**"的对称感：对方在自己的强项上被碾压，连退路都没有。它属于"物质/地位收获"维度的爽点（源文档明确指出这类爽点与打架打脸同等有效），对都市题材尤其适用。

关键手法：**让对方先尽情展示**（展示得越充分、越得意，被打脸越疼），**主角后手亮出碾压物**（要具体：限量款 vs 定制款、藏品 vs 传世珍宝、技能 vs 更高层次），**碾压物要"举重若轻"地拿出**（主角漫不经心，显得对方格局小）。落点可以是配角"羞愧离场/强行挽尊/当场破防"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 富家公子炫富被碾压
- **问题**: 富二代当众炫富羞辱主角，如何反制？
- **方法论的使用**: 让对方先炫耀（跑车、名牌、派对），主角后手展示更高层次（家族产业、定制座驾、顶级人脉）。
- **结论**: 在自己的强项上被碾压，退路全无。
- **结果**: 富二代破防，旁观者从"看主角笑话"转为"看富二代笑话"。

### 案例 2: 配角炫耀珍藏物件，主角拿出更好的
- **问题**: 配角炫耀自己的珍藏（古玩/藏品），如何打脸？
- **方法论的使用**: 主角拿出同类但更高级的物品（真品 vs 赝品、传世 vs 限量）。
- **结论**: 收藏品层面"识货"的分层（配合 a07 物件反差）。
- **结果**: 配角藏品被比下去，颜面扫地。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 都市/豪门题材需要"物质打脸"戏（比钱、比藏品、比排场）。
2. 需要"以彼之道还施彼身"的对称性反转。
3. 剧本爽点偏战斗，需要补充"物质/地位"维度的爽点（多维爽点原则）。
4. 校验剧本：检查打脸戏是否有"让对方先展示再碾压"的对称结构。

## E — 可执行步骤 (Execution)

1. **设计配角的炫耀资本**
   - 完成标准: 明确配角炫耀的具体内容（财富/藏品/技能/人脉/排场），并让炫耀"够充分"（具体细节、得意姿态）。
2. **让配角尽情展示（含羞辱主角）**
   - 完成标准: 炫耀戏包含具体展示动作 + 顺带贬低主角（"你也配？"），积累观众反感与主角反差空间。
3. **主角后手亮出碾压物**
   - 完成标准: 碾压物与炫耀物同类但更高层次（真品/定制/传世/更高技能），拿出姿态举重若轻（随手/漫不经心）。
   - 判停条件: 若主角拿不出碾压物（设定不符），改用"主角不接招但更高维度碾压"（如对方炫钱，主角炫的是不稀罕钱的境界），或切换 c02/a07。
4. **安排配角破防与旁观者反应**
   - 完成标准: 配角破防反应（强辩/羞愧/当场离开），旁观者态度反转（从看主角笑话到看配角笑话）。
5. **校验合理性**
   - 完成标准: 碾压物有来源与可信度（主角确实拥有/做得到），避免"凭空变出"；配角炫耀符合其设定（非强行降智）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对方未主动炫耀——没有"先展示"的铺垫，碾压无对称感。
- 主角碾压物无来源（凭空出现）——需要设定背书。
- 武力比拼场景（归 b 类）。

### 作者在书中警告的失败模式

- **无脑装 X**: 主角的碾压物来得莫名其妙（昨天还穷，今天直接全球首富）——需要铺垫主角的真实背景。
- **强行降智**: 配角已见识主角的碾压物，下一场仍用同样的东西炫耀——信息暴露后要换炫耀物或换策略。

### 作者的盲点 / 时代局限

- "比钱多"叙事在强调精神价值的题材中可能显得肤浅；可迁移为"比见识/比格局/比审美"等高阶维度（对方炫俗，主角炫雅）。

### 容易混淆的邻近方法论

- 与"借势装 X"(c04) 混淆：分界是炫耀资本的真假——真资本被更强的碾压用本 skill，假资本被戳穿用 c04。
