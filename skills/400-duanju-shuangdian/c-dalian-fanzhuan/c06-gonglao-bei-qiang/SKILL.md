# 功劳被抢真相大白 — 迟到的正义更解气

## R — 原文 (Reading)

> 他人抢夺主角功劳，后续真相大白。
>
> — 《400 个爆款短剧剧本爽点》，三、打脸反转・当众处刑

## I — 方法论骨架 (Interpretation)

主角的功劳/成果/战利品被他人（同事、亲戚、上司、同门、反派）**抢夺冒领**——抢功者靠主角的成果获得荣誉、地位、奖励，主角暂时隐忍或被迫让出（常因证据不足/地位低/被胁迫）。随后真相大白，抢功者的虚假光环崩塌，身败名裂，主角拿回属于自己的一切。

这个桥段的爽点核心是**"延迟满足"**：抢功者爬得越高，摔得越重。读者憋着"这明明是主角的"的气（压），看着抢功者一路风光（憋屈加剧），直到真相大白那一刻集中释放（弹）——"迟到的正义"比即时正义更解气。

关键手法：**"压"要写足**——抢功行为具体（当众冒领、窃取成果、反咬主角），主角被迫让出要有合理原因（证据被毁/地位悬殊/受胁迫），让读者憋屈；**"弹"要够狠**——真相大白要当众、有确凿证据（原始记录、证人、技能展示、第三方验证），抢功者的每一个风光时刻都被清算。

## A1 — 书中的应用 (Past Application)

### 案例 1: 他人抢夺主角功劳
- **问题**: 同事/同门冒领主角成果，如何清算？
- **方法论的使用**: 主角隐忍（或收集证据），在成果验收/表彰大会上当众揭穿（原始记录/亲自演示）。
- **结论**: 抢功者爬得越高，摔得越重。
- **结果**: 抢功者身败名裂，主角拿回荣誉与奖励。

### 案例 2: 反派抢夺主角战利品/宝物（与 c04 配合）
- **问题**: 反派靠抢来的功劳上位，如何一次性清算？
- **方法论的使用**: 主角在反派最得意的场合（受封/庆典）揭穿真相，且安排多个受害者一起指证。
- **结论**: 多人指证 = 证据链完整，抢功者无处可逃。
- **结果**: 反派连环崩塌，主角沉冤得雪。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 职场/宗门/同门题材：成果被冒领的经典冲突。
2. 需要"憋屈蓄力 → 集中爆发"的节奏（延迟满足型爽点）。
3. 长线伏笔：抢功者一路风光，为最终清算蓄力。
4. 校验剧本：检查是否缺少"正义清算"类反转（全是即时打脸，缺少延迟满足）。

## E — 可执行步骤 (Execution)

1. **设计功劳与抢夺行为**
   - 完成标准: 明确主角的成果（成果/战利品/方案/技能）与抢功者抢夺的具体行为（冒领、窃取、反咬），抢夺要具体可恨。
2. **让主角"被抢"合理（压的成立）**
   - 完成标准: 主角让出/被抢有合理原因（证据被毁/地位悬殊/受胁迫/隐忍顾全大局），读者憋屈但理解；避免主角"毫无反应地白送"。
3. **让抢功者风光（蓄力）**
   - 完成标准: 抢功者凭借抢来的功劳获得荣誉/奖励/地位（受封、表彰、升职），至少 1 场风光戏让读者憋屈加剧。
4. **设计当众真相大白（弹）**
   - 完成标准: 揭穿有确凿证据（原始记录/证人/亲自演示/第三方验证），在抢功者最得意的场合当众进行；抢功者狡辩被逐一驳倒。
   - 判停条件: 若无法安排"当众"揭穿（无公开场合），可改用"私下对峙 + 证据公开"两段式，但须保证清算结果公开可见。
5. **落点：夺回 + 追责**
   - 完成标准: 主角拿回荣誉/奖励/战利品；抢功者承担后果（身败名裂/赔偿/被逐）；后续留口子（主角声望借此更上一层）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 功劳归属无争议的剧情——没有"抢"就没有反转。
- 主角当场就把功劳抢回来的即时冲突——那是当面对质类桥段，非"延迟满足"结构。

### 作者在书中警告的失败模式

- **强行降智**: 抢功者已被揭穿一次，下一段剧情仍凭同一份假功劳风光——证据公开后必须让抢功者失去信誉。
- **无脑装 X**: 主角被抢后毫无情绪、毫无动作（全程被动等真相）——建议写主角暗中收集证据/布下后手，主动参与清算。

### 作者的盲点 / 时代局限

- "隐忍复仇"叙事可能强化"忍气吞声"价值观；现代题材中建议主角在隐忍期有"暗中行动"（收集证据、经营实力），避免纯被动受气。

### 容易混淆的邻近方法论

- 与"信息差"(d03) 的关系：本 skill 依赖信息差（读者知道真相、众人不知道），但核心落点是"功劳归属清算"，不是信息差的泛化应用。
