# 成长的烦恼梗库

## 编剧卡住，先查现成梗

1. 从用户的场景里找出「谁想让谁做什么，哪一步卡住」。选动作、关系或后果作检索词。例如，孩子去找自认好说话的家长，搜 `求情`；想让冒充者自己出错，搜 `假身份 露馅`。用户给了集号、英文集名或人物，就带上这些限定。
2. 在 intake 项目根目录运行 `python3 剧本系统/skills/trope-library/trope-library.py growing-pains 求情 --limit 8`。数据在本技能的 `cards.jsonl`，每行一张。把 `求情` 换成当前关键词，去掉关键词可浏览。搜索按相关度排列，可能返回只命中部分词的卡。限定集号时核对 `episode`。要某集全部已收录卡时用完整集标搜索，`--limit` 调到库的总行数，筛出 `episode` 相同的所有行。
3. 查看每张卡的 `beat` 和 `formula`。选能改变当前场面下一步、又各有不同因果的卡。命中少时换成角色实际会做的事再查，例如从「反转」改查「求情」「租金」「礼物」。需要的机制没有已入库例子，就说明检索到哪里，不用相似关键词硬配。
4. 给出「集名和时间｜原剧谁做了什么、结果怎样｜可迁移公式｜放进用户这场的具体动作」。每张保留一个可在原稿中逐字查到的 `anchor`。写改编时标明「套进你的戏」，沿用用户的人物关系、道具和场景限制。只问出处或单集清单时，直接给卡和证据。

## 指定集要拆全，或跨集找同构

- **补拆一集**：先用该集梗卡的 `source` 打开 `docs/materials/videos/<source>`。未入库时用 `rg --files docs/materials/videos | rg -i 'Growing Pains .*\.md$'` 按文件名找集号、上下集与重名版本。看标题、音轨时长、时间段和内容是否一致。对分集身份有疑问时先记为候选。
- 从第一段读到结尾，按换场和行动转折记下每条线的「谁要什么→谁做了什么→别人如何回应或处境怎样改变」。再从结尾倒查每个回扣的铺垫。主线、小支线、反复出现的道具和自成因果的局部笑点都要回看；同一动作的换名留一张，新的策略产生独立后果才另列。逐场对账，写明读过的时间范围、可确认项及缺口。
- **证据分界**：动作和后果均能从连续对话或前后两个时间段核回，列为「转写可核」。为转折保留时间段和一段原样短引，跨场因果补早晚两处定位。只有片名、一个关键词、人物身份不明或依赖未核画面时，列「候选」并指出差哪一步。若有本地视频，回看对应位置再决定。原始 ASR 的错词可原样保留在短引里，中文说明只写上下文能支持的事。
- **跨集查询**：先在库中按动作搜出候选，按因果分组，回核每个入选例的触发与后果。认为两集同构时写清共享的是哪次选择、各自代价差在哪。要求查遍指定范围时，逐集检查该范围的原稿，列出已查、无匹配、缺稿或存疑的集。只查卡库时把结果称为「已入库命中」。
- 用户明确要求补库时，照现有七字段追加。`source` 相对 `docs/materials/videos`，`anchor` 原文连续，`beat` 以证据所在分段时间起笔。同一段在回顾集重播时不另算首创。候选、仿写与自拟笑料单列于答复，不入事实卡。

粒度可参照《哆啦A梦》动物饼干的说明例：拿错道具→效果倒计时→必须遮掩→打电话支开旁人→遮掩反过来制造麻烦。每一箭头都要回答「为什么引出下一步」；步骤数量和桥段可以完全不同。真实检索与套用见 [示例](references/example.md)。
