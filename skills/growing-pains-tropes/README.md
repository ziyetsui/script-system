## 两轮示范

**第一轮**用表格第一条提示词。示范回答：

- **101 Pilot，00:13:51–00:14:07**。迈克嫌两个月禁足太长，找爸爸向妈妈求情，这才知道原先只罚一个月，多出来的一个月就是爸爸加的。回搜 `originally it was one month`。移到社团里，先写学生私下找到最和气的指导员，让指导员说：「原来只用赔油漆。工时是我让他们算进去的。」
- **115 Slice of Life II，00:09:18–00:09:31**。还不起钱的人讲兄弟情，声称互相帮忙比钱重要，弟弟顺势让他做一整个周末的仆人。回搜 `my personal servant`。如果场上只能有学生和道具师两人，就让学生主动说「算钱就见外了，大家靠的是搭把手」，道具师再把排班表铺开。

**确认点**是学生究竟会错意、找错了人，还是被自己说的话套住。选后一种就可以继续：

> `/成长的烦恼梗库 用 115 那个写法。只留学生和道具师，把讨价还价写成四句。学生主动提出比钱更值钱的东西，最后一句让他刚想走又停下来。`

**第二轮示范回答，以下为新写对白**

学生：「这点漆还单给我开张单子？咱们搭台靠的是人情。」  
道具师：「那就不算漆钱。你愿意搭几把手？」  
学生：「缺人尽管喊。那我先——」  
道具师：「别脱手套，周末那三车布景，司机已经到门口了。」

## 查库与核证

在 `2026-11-19-project-intake` 根目录运行。第一条按编剧卡点查，第二条取试播集的已收录卡。

```sh
python3 剧本系统/skills/trope-library/trope-library.py growing-pains 求情 --limit 8
python3 剧本系统/skills/trope-library/trope-library.py growing-pains 'Growing Pains 101 Pilot' --limit 288
```

[梗卡数据](cards.jsonl) 每行含一张卡的集名、原稿相对路径、连续短引、梗名、适用卡点、带时间的原剧情因果及迁移公式。`source` 以 `docs/materials/videos/` 为起点。英文引用保留转写的拼写，时间定位到一段对白。另见 [带上下文的查库与回搜示范](references/example.md)。

本地目录有 **159 份转写、158 个不同集标**。313 的短稿只有 02:48，使用同集 23:37 的长稿取证。**1 个本地集标未入库**：419 的清洁工误认、催学习等段落与 418 重合，419 的独立剧情待核。303 只存 08:36，卡片限于该片段。101 已从头读到尾，其余集按所取片段前后文核证。这个覆盖数说的是能按集调出梗卡的范围，其他尚未逐场核完的机制和依赖画面的笑点仍可补拆。
