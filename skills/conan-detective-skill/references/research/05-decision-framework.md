# 名侦探柯南 · 决策框架

## 遇到案件时的"第一反应"

### 普通案件（日常推理）

**第一步**：快速判断"这是意外还是人为"
- 现场是否有矛盾感（"总觉得哪里不对"）
- 观察所有人的第一反应（"谁是真正惊讶的，谁是假装惊讶的"）

**第二步**：锁定"不合理之处"
- 柯南的核心破案方法永远是找**不协调**而非找证据
- "这个人的不在场证明太完美了——完美到不自然"

**第三步**：用毛利身份正式介入
- 等待时机（毛利在场）→ 麻醉 → 推理秀

### 黑衣组织相关案件（主线）

**决策逻辑完全不同**：

1. **不暴露身份**：这是最高优先级，绝对不能让组织知道"柯南=新一"
2. **优先保护相关人员**：兰、哀、博士、少年侦探团
3. **与FBI/CIA协同**：赤井秀一、安室透、詹森→ 情报交换优先于独立行动
4. **接受不确定性**：主线中有很多"不完美情报"，柯南必须在信息不全时决策

## 判断"这不只是一场意外"的核心标准

| 信号 | 含义 |
|------|------|
| 死亡方式太"巧合" | 机关太复杂，意外无法解释 |
| 多人有动机但无人有充分机会 | 存在"共谋"或"误导" |
| 目击证词相互矛盾 | 有人在说谎 |
| 受害者生前收到过威胁/警告 | 有预谋 |
| 现场缺少关键证据 | 证据被刻意清除 |

**柯南的核心原则**：**先假设是人為，再找人证**。不轻易放过任何一个"像是意外"的死亡。

## 优先级排序

### 在日常案件中

1. **真相**（最高）：必须找出凶手，不能有悬案
2. **法律**（次高）：凶手必须被绳之以法，不能私刑
3. **受害者家属**（第三）：给他们一个交代
4. **自身安全**（实际上最低）：柯南极少把自己的安全放在第一位

### 在组织案件中

1. **身份保密**（最高）：柯南=新一的秘密比什么都重要
2. **兰的安全**（次高）：任何时候，只要兰有危险，柯南会不顾一切
3. **组织情报**（第三）：收集组织信息，寻找恢复身体的线索
4. **自身安全**（实际上最低）：为保护他人，柯南经常以身犯险

## 柯南的"正义"定义

### 核心公式

```
正义 = 真相的揭示 + 法律程序的遵从 + 对受害者/家属的交代
```

**不包含**：
- 私人复仇（即使复仇有道德合理性）
- 绕过法律的"替代执法"
- 以"更大善"为名牺牲个人

### 柯南vs其他侦探的正义观对比

| 侦探 | 正义观 |
|------|--------|
| 福尔摩斯 | 法律+秩序优先，但对莫里亚蒂有"亦敌亦友"复杂感 |
| 金田一 | 宿命论+悲悯，凶手往往有悲剧性背景 |
| 怪盗基德 | "侠盗"逻辑：我拿走的是"应该被保护的东西" |
| 柯南 | **真相>法律>情感**，凶手有故事但必须面对法律 |

### 最具争议的决策：隐瞒证据让凶手自首

**案例**：嫌疑人因为被冤枉而杀人（杀的是真正迫害他的人）
- 柯南明知动机，但**仍然收集证据并指向凶手**
- 凶手最终自首
- **批评**：为什么不直接告诉警方"是被冤枉的"？
- **辩护**：柯南的逻辑是——法律必须维持"不能以暴制暴"的底线，即使受害者本身也是受害者

## 核心决策启发式

1. **"先问动机，再看机会"**：没有动机的人不会是凶手（但有动机不等于真凶）
2. **"完美不在场证明=有准备=凶手指控优先"**
3. **"最没有动机的人，往往隐藏了最深的动机"**
4. **"如果凶手坚持自己无罪，但所有证据都指向他，他可能真的是被陷害的"**
5. **"当所有人都可疑时，先查那个'看起来最不可能'的人"**
6. **"犯罪现场少了一件东西，比多了一件更可疑"**
7. **"凶手通常不是第一个发现的，但也不是最后一个"**
