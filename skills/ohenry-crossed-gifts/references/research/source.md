# 欧亨利交叉赠礼的原书依据

## 来源与定位

《欧·亨利短篇小说选》。以下行号按项目所供中文 Markdown 转写本，从 1 起计。

## 原创示范

**改前**　姐妹穷，各自买了小礼物，说彼此最重要。

**改后**　姐姐卖了唯一的相机，给妹妹的唱机配了一枚好唱针。妹妹卖掉唱机，买了姐姐一直租用的镜头。拆包时姐姐伸手去拿相机试镜头，摸到空架子；妹妹把唱针搁在原来放唱机的方印中央。

**拿掉一处再读**　只让妹妹保留唱机，哪件礼物能当场使用？两个人在不知道对方计划时，各自的购买理由成立吗？
