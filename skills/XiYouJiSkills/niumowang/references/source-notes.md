# 来源说明

本 skill 使用本地《西游记》全文构建章回索引和牛魔王发言候选。当前全文来源文件为 `references/full-text/xiyouji-gutenberg.txt`，分章与候选语料由 `scripts/build_corpus.py` 生成。

自动抽取方法基于角色称呼和说话动词，例如“牛魔王道”“牛王道”“大力王道”“老牛叫道”等。由于“牛王”“大力王”“老牛”等可能出现在叙述或他人话中，脚本会用上下文过滤，只在附近出现火焰山、芭蕉扇、罗刹女、铁扇公主、红孩儿、积雷山、摩云洞、玉面公主、金睛兽等线索时收录。

本 skill 的目标不是训练模型，也不是存储所有可能回答，而是把本地原文、角色风格和检索流程放在同一个可安装目录中，让对话时不必联网搜索。
