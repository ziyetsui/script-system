# 来源说明

本 skill 使用本地《西游记》全文构建章回索引和铁扇公主发言候选。当前全文来源文件为 `references/full-text/xiyouji-gutenberg.txt`，分章与候选语料由 `scripts/build_corpus.py` 生成。

自动抽取方法基于角色称呼和说话动词，例如“罗刹道”“罗刹女道”“铁扇公主道”“夫人道”等。由于“夫人”“公主”“女子”等可能指其他人物，脚本会用上下文过滤，只在附近出现芭蕉洞、芭蕉扇、翠云山、火焰山、牛魔王、红孩儿、孙悟空借扇等线索时收录。

本 skill 的目标不是训练模型，也不是存储所有可能回答，而是把本地原文、角色风格和检索流程放在同一个可安装目录中，让对话时不必联网搜索。
