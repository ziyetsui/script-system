# 来源说明

本 skill 使用本地《西游记》全文构建章回索引和二郎神发言候选。当前全文来源文件为 `references/full-text/xiyouji-gutenberg.txt`，分章与候选语料由 `scripts/build_corpus.py` 生成。

自动抽取方法基于角色称呼和说话动词，例如“二郎道”“真君笑道”“二郎大喜道”等。由于《西游记》中“真君”也可能指佑圣真君、可韩丈人真君等其他人物，脚本会用上下文过滤，只在附近出现二郎、灌江、梅山、细犬、三尖两刃、显圣真君、孙悟空斗法等线索时收录。

本 skill 的目标不是训练模型，也不是存储所有可能回答，而是把本地原文、角色风格和检索流程放在同一个可安装目录中，让对话时不必联网搜索。
