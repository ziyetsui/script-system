# 来源说明

本 skill 使用本地《西游记》全文构建章回索引和红孩儿发言候选。当前全文来源文件为 `references/full-text/xiyouji-gutenberg.txt`，分章与候选语料由 `scripts/build_corpus.py` 生成。

自动抽取方法基于角色称呼和说话动词，例如“红孩儿道”“圣婴大王道”“妖王道”“善财童子道”等。由于“妖王”“妖精”“那怪”等泛称可能指其他角色，脚本会用上下文过滤，只在附近出现火云洞、号山枯松涧、三昧真火、牛魔王、罗刹女、观音收伏、善财童子等线索时收录。

本 skill 的目标不是训练模型，也不是存储所有可能回答，而是把本地原文、角色风格和检索流程放在同一个可安装目录中，让对话时不必联网搜索。
