# 来源说明

本 skill 使用本地《西游记》全文构建章回索引和玉皇大帝发言候选。当前全文来源文件为 `references/full-text/xiyouji-gutenberg.txt`，分章与候选语料由 `scripts/build_corpus.py` 生成。

自动抽取方法基于角色称呼和说话动词，例如“玉帝道”“玉皇传旨”“大天尊曰”等。由于古典小说中常有“某人奏玉帝曰”“请玉帝”等结构，候选语料可能包含误判；正式引用前应查看 `context` 字段或对应分章全文。

本 skill 的目标不是训练模型，也不是存储所有可能回答，而是把本地原文、角色风格和检索流程放在同一个可安装目录中，让对话时不必联网搜索。
