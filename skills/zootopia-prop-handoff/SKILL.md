# 疯狂动物城道具

处理的问题是**道具怎样通过交接改变人物关系**。从用户贴的原稿、指定的场次和想保住的人物选择开始。缺少原稿时，以用户提供的点子作一段标为原创的试写。

## 改稿步骤

1. 摘取暴露问题的原句，指出哪两处动作或信息之间缺少联系。读[原书依据与完整示范](references/research/source.md)，用一处书中动作或论点说明它和此稿的联系。
2. 给道具只有一个可辨认的基本功能。逐次记谁拿着、谁见过它有效、谁当面用给谁看。让每次交接表达一次主动授权、试探、拒绝或回应，使结尾的使用者既有机会又有知识。
3. 在稿上做一次练习。逐次写“谁持有／谁知道功能／当着谁的面使用／用后谁能替谁做主”。交接发生在场外就标为待补；若功能到结尾才出现，把一次普通使用移到前面。保留人物可以拒绝接手的时刻。
4. 先交修改的局部，再给一项作者可以立即做的复核。把为了示范新补的事实写明，尊重用户指定的结局。

场次｜持有人｜知道用途的人｜动作改变的关系。删掉第一次展示，问结尾的使用者从哪里学会；撤掉交接，再问他如何拿到。

## 心智模型 · 读稿时要拆开的三件事

### 在场与知情

同处一室并不保证看见操作。交代谁亲眼看过功能，结尾才能由那个人使用。

### 交付与授权

同一物件既能逼人合作，也能交给对方表达信任。记下每次谁可以拒绝。

### 用途与证据

早先的普通使用建立功能，最后一次使用解决具体争议。局限是读本没有记的镜位和剪接不能由情节反推。
