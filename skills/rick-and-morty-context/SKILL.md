# Rick and Morty translation context

# Rick and Morty 字幕翻译背景

## 项目优先级

项目权威词表优先于历史字幕、网页资料和临时译法：

- Rick = 瑞克
- Morty = 莫蒂
- Summer = 夏茉
- Beth = 贝丝
- Jerry = 杰瑞

角色全名：

- Rick Sanchez = 瑞克·桑切斯
- Morty Smith = 莫蒂·史密斯
- Summer Smith = 夏茉·史密斯
- Beth Smith = 贝丝·史密斯
- Jerry Smith = 杰瑞·史密斯

任何上下文都保持上述短名，不改成“瑞奇”“莫迪”“夏美”“贝丝特”或“杰瑞德”等变体。

## 角色与关系

- **瑞克·桑切斯**：贝丝的父亲、莫蒂与夏茉的外公；天才科学家、发明家、酗酒者和强烈的反权威人物。表面冷酷、自恋、犬儒，常以羞辱、炫耀知识和粗俗玩笑控制谈话；深层动机包含失去亲人后的创伤、孤独和对家庭的依恋。
- **莫蒂·史密斯**：瑞克的外孙、夏茉的弟弟；善良、焦虑、容易结巴和慌乱，通常承担道德反应与观众视角。长期冒险使他逐渐更有主见，偶尔会反驳瑞克或独立行动。
- **夏茉·史密斯**：莫蒂的姐姐、贝丝与杰瑞的女儿；青少年口吻明显，关注同龄人评价、恋爱、社交和自我形象。她比莫蒂更主动、更敢冒险，逐渐成为瑞克可靠的搭档。
- **贝丝·史密斯**：瑞克的女儿、莫蒂与夏茉的母亲、杰瑞的妻子；职业为马类外科医生。聪明、能干、尖锐，常在家庭责任、自我价值、父亲认同和冒险欲望之间摇摆。
- **杰瑞·史密斯**：贝丝的丈夫、莫蒂与夏茉的父亲、瑞克的女婿；缺乏安全感、爱抱怨、事业不顺，常被瑞克贬低为无能或失败者。其怯懦、虚荣和偶尔的善意构成家庭喜剧的重要来源。
- **邪恶莫蒂（Evil Morty）**：莫蒂的另一版本；冷静、独立、善于操纵，反对瑞克—莫蒂体系对莫蒂的依附和控制。译名固定为“邪恶莫蒂”。
- **太空贝丝（Space Beth）**：贝丝的太空行动版本或克隆相关版本；固定保留“太空贝丝”。

关系的核心并非单纯的祖孙搭档：瑞克把莫蒂当助手、遮蔽脑波的伙伴和情感纽带；莫蒂依赖瑞克的能力，却持续抵抗其操控。贝丝在父亲与丈夫、家庭稳定与冒险自由之间反复选择；杰瑞与瑞克构成长期的女婿—岳父冲突。多元宇宙会出现同名异体，涉及身份时优先保留原名、编号或形容词，不擅自合并人物。

## 世界设定

故事以美国郊区史密斯家为日常基地，同时延伸到外星球、异维度、模拟现实、时间分支和多重宇宙。瑞克的车库是实验室，传送枪与飞船让家庭生活和宇宙级危机随时互相侵入。

剧中“维度”“现实”“宇宙”“时间线”并非每次严格同义：根据英文原句和画面判断。涉及不同版本角色时，维度编号是身份标签，不必润色成中文地名。

- **多重宇宙（multiverse）**：存在无数平行现实，同一角色可有大量版本。
- **中央有限曲线（Central Finite Curve）**：由瑞克体系建立的现实边界，隔离出瑞克占据智力优势的宇宙集合。
- **瑞城（Citadel of Ricks）**：由多个瑞克及莫蒂组成的跨维度社会与政治机构。英文出现 Citadel of Ricks 时优先译“瑞城”，需要强调组织性质时可译“瑞克城”。
- **传送枪（portal gun）**：跨维度移动与战斗装置；**传送液（portal fluid）**是其关键材料。
- **仿真与记忆技术**：模拟现实、脑内空间、记忆提取与记忆清除经常被用于惩罚、逃生和身份反转。

## 总体剧情前提

瑞克回到女儿贝丝的家庭，并把外孙莫蒂拖入高危科学冒险。每集通常有一个相对独立的科幻或类型故事，同时推进家庭矛盾、瑞克的创伤、莫蒂的成长以及多元宇宙政治。

全剧横跨多季，连续主线与单集荒诞故事并行，翻译时不能只按某一季的状态理解角色。瑞克的技术几乎能解决任何物理问题，却经常制造更大的伦理、情感或社会后果。

喜剧效果来自“宏大宇宙危机”和“美国中产家庭琐事”的并置：外星战争可能由婚姻争吵触发，家庭聚餐也可能牵连多个现实。

## 说话风格与翻译策略

- **瑞克**：高速、打断多、句子松散，常带 burp、脏话、反问、技术术语和自我吹嘘。保留攻击性与节奏，避免翻成整洁的科普腔。
- **莫蒂**：犹豫、重复、结巴、突然提高音量。紧张时保留少量重复词和口语停顿，避免每句都人为加“呃”。他的伦理质疑要清晰。
- **夏茉**：青少年俚语、社交媒体式表达和直接吐槽较多。中文可使用当代口语，但避免过度网络化导致年代感失真。
- **贝丝**：语气理性、尖锐，带成年人的疲惫和自嘲；家庭争执中常比其他人更有控制力。
- **杰瑞**：自我辩护、套话、受伤后的抱怨和不合时宜的自信；保留尴尬感，少用过于机智的译文。
- **外星人、机构和广告**：可使用庄严、官僚或商业化语体，再与粗俗内容形成反差。
- **脏话与性笑话**：Adult Swim 面向成人，粗俗、身体幽默和禁忌笑话属于风格组成部分。根据角色身份、场景和时长压缩，但避免无差别净化。
- **双关与文化梗**：先确认笑点对象，再决定直译、音译、功能对等或保留英文。不要添加字幕中没有的解释。

## 文化语境

本剧属于 Adult Swim 的成人动画传统，将情景喜剧家庭结构、硬科幻、恐怖、超级英雄、动作片、电子游戏和互联网文化混合在一起。

常见喜剧机制包括：

- 类型模仿
- 快速文化引用
- 第四墙意识
- 广告腔与学术腔的突然切换
- 美国郊区日常与宇宙尺度灾难的并置

文化引用有时只是笑点，有时用于讽刺资本、官僚机构、家庭权力或“天才”崇拜；字幕应先传达当下台词功能，再考虑是否保留典故。

全剧常以犬儒、虚无感和荒诞暴力制造反差，但人物之间仍有持续的情感牵引。不要把瑞克简单译成全知全能的正面英雄，也不要把莫蒂、贝丝、夏茉和杰瑞的家庭争执处理成纯粹闹剧；许多笑点依赖真实的羞耻、依恋、创伤和责任冲突。
