# 契诃夫改判

处理的问题是**人物随责任人身份改变裁断**。从用户贴的原稿、指定的场次和想保住的人物选择开始。缺少原稿时，以用户提供的点子作一段标为原创的试写。

## 改稿步骤

1. 摘取暴露问题的原句，指出哪两处动作或信息之间缺少联系。读[原书依据与完整示范](references/research/source.md)，用一处书中动作或论点说明它和此稿的联系。
2. 固定一件事故、一处损伤和同一个说了算的人。每回只换一条有关责任人身份的消息，接一句能让旁人照办的命令。沿同一张赔单或同一个受罚的人追踪后果。
3. 在稿上做一次练习。把事故、损伤和主事人钉在原处。写三条关于责任人身份的消息，每条后面紧跟一道可执行的命令，标明谁承担损失。用命令显示势利，把“他见风使舵”删掉。
4. 先交修改的局部，再给一项作者可以立即做的复核。把为了示范新补的事实写明，尊重用户指定的结局。

## 本技能的工作表

同一物证｜传来的消息｜当众发的命令｜这回谁吃亏。删去评价词，读者能否从命令看出立场？

## 心智模型 · 读稿时要拆开的三件事

### 事证与身份消息

每轮分开列受损事实和新传闻。事故始终没变，说话者才有机会在同一件事上暴露立场。

### 脾气与权力

光是说得越来越响，受罚者可能没变。要找谁能命令别人赔钱、放行或道歉。

### 最后一次改口

可让最后一道命令把负担完整推回别人身上。局限是现实情节若有新的决定性证据，重新判断本就合理。

## 边界与适用条件

截至 2026-11-26，本包沿用项目已核实的中文书本采样。

- 如果新消息真正改变了事故责任，改判可能合理。想讽刺势利，就把有关事故本身的新证据拿掉再试。
- 本稿的自拟台词、动作和结局应标注“原创试写”。
- 个人审稿口吻、未见版本或拍摄决定需要独立材料。

## 表达与张力

**这道练习的张力**　讽刺愈鲜明，人物也愈容易扁平。保留人物替前后矛盾找借口时的小动作，让读者自行察觉。 描述时先说篇中谁做了什么，再给本次归纳的用法。
