# 书库技法

`/书库技法 三次上门求助写得像同一场。请保留人物和结尾，帮我改中间一次。` 后面可以直接贴大纲、场次或台词。与导演评审共用一份大纲时，直接从这份原稿取证，独立交付文字修改。用户同时要两种意见时，让这份改稿保有自己的原句、理由和复核问题。

## 从稿面选一道练习

先摘原稿中最能看出问题的句子，标出场次和用户要保留的条件。把“太平”“不感人”写具体，例如“第二次请求被拒以后，他第三次仍带着同一条件找同一个人”。用户只给题目时，用一句标明“自拟”的练习底稿起步。用户点了书或篇名，读表中对应的独立技能，直接按其工作表改这份稿。只装本入口时，使用随包练习卡完成同一项任务。

**遇到“三次”先做换序试验。** 把第二次挪到第一次前，找一句会失去前因的话。再补完“到第三次，已经变了的是＿＿”。若是对权势归属的消息左右裁断，选《变色龙》；若是帮助者剩下的东西或能力，选《快乐王子》；若是同伴还肯不肯信、旧解法还能不能用，选《西游记》；若是道具掌握在谁手里、谁能借它开口，选《疯狂动物城》。有两项同时变，选直接造成结尾决定的那一项。三回完全同效时，先试合并一次；若用户要保留三回，把其中一种变化写进第二回，再回头检查第三回。

## 把练习交还给作者

1. 打开选中的练习卡，读“书中依据”，用一句话说明这段原稿与它的具体联系。方法书可以转述作者主张；小说与童话只陈述篇中动作，把归纳称作“从这段可练”。引中文措辞标明译本；双语故事读本只支持文字情节。每卡的行号对应项目本地 Markdown，从 1 起计。
2. 按卡上的步骤在用户原稿上实际做一次。并排给**改前、改后**，保留已有角色、设定与指定结局。把为练习补出的关键事实标成“试写设定”，让作者决定是否接纳。卡中自拟例子供缺稿练习，也可用来解释步骤。
3. 留一至两个可对着改稿回答的问题，并给出本次试读的答案或仍缺的伏笔。若两次事件互换后仍然成立，或去掉新道具也不影响决定，回到原稿再改一次。用户只要练习题时，展示示范，把对用户稿的作答留给用户。
