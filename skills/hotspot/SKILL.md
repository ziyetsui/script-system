# 找热点，挑出康家能演的那件事

**推荐之前，先说得清：从素材里借哪一点，到了康家谁想做什么，另一个人为什么会有不同反应。** 编剧看完能决定用作主线、只借背景，还是换题。

1. **认输入。** 读 `$ARGUMENTS` 和本轮任务。没有主题、编号或具体素材时，只问「这集想找哪个主题的热点？回数字，或直接说一个小主题，比如爱国、睡眠、生活自理。」随问逐行展示下方「主题菜单」的七项及括号内全部子题。七项之后每次默认附一条「本轮推荐主题」，再列时段和条数。结合编剧已给的领域或偏好，比较哪些子题能把社会议题落到孩子有代价的选择上，从中推荐一个编号和子题。用两句具体写明：可尝试的北京日常小事、它连接的公共行动或时代变化、孩子因此要作的决定，以及对应的总纲价值与社会主义核心价值观。未检索时把例子写成创作设想；没有指定领域也给一个可探索的首选，保留编剧自由选择。菜单末尾用一行显示本轮时段和目标条数，缺省为「近 3 个月，10 条」。提示可选时段「近 1 个月 / 近 3 个月 / 近半年 / 自定起止日期」，条数「3 / 5 / 10 / 自填正整数」，例如 `7 近半年 5条`。让编剧知道还可以加想搜的领域，例如 `1 爱国 航空 近半年 5条`；检索时结合子题和领域。等用户选主题时保留前面已给的时段和条数。主题已给就直接执行；时段与条数独立取默认，任一项可单独改。单独回 `1` 至 `7` 视为主题编号，带「条」的数字是条数。只给编号就按整类查；同时给了子题就按子题查。完整提问与短命令走同一流程。
2. **定范围。** 读[创作大纲](<../../docs/harness/北京一家人-创作大纲-520集.md>)的「主题阐述」「核心价值观：润物无声，深度融入」和涉及的人物设定，沿用本轮已确认的限制。新闻默认从执行日倒推三个日历月；用户指定日期或只准使用所给材料时，以其范围为准。若给的是成语或寓言并要求故事新编，先用一句话提炼其价值，再给三件当代北京孩子可能遇到的事，标为虚构设想，交编剧挑。若明确要求为典故找新闻，仍走新闻检索。
3. **打开报道再提名。** 按主题和具体行动查新闻。逐篇打开原文，记下发布者、发布日期、链接，及文中能找到的一个人、物件或动作。历史题说清近期发生了什么（如展品最近展出）和旧事发生于何时。两份材料冲突时列明各自出处和说法，未决细节标「待核」；若影响核心判断，该条留作线索。原文打不开、只有搜索摘要或旧 AI 回答时，换来源；仍无依据就说明缺口。候选不足时按实交付。
4. **试一场康家的戏。** 写出小宁看见什么、会问哪句话、因而主动做什么。给家人或伙伴一个同样说得通的动机。例如，妈妈忙忘了奖励，孩子却记得每一次处罚。拿掉周年数字和热搜标签，问这件事放在十年后还能不能让人理解。这里定的是「能否作所选子题的主线」。写结论前先填两格：①原场合，孩子因为什么做了什么；②换成普通场合，孩子因为什么做了什么。两格的决定及理由相同 → 交稿标题标「背景」，写一句这段戏实际在讲什么，到此结束该题定级。两格不同 → 引用候选原稿中支撑差异的台词或动作，再标「主线」。找不到原稿证据也标「背景」。两格只用现稿，新增动机属于下一轮改写。最动人的行动只能由新闻当事人完成时，说清只借哪件物品或哪层背景；只剩主题口号就换题。

5. **选热点就检验以小见大。** 对新闻和典故的当代切口都问：孩子眼前哪件小事，连着哪项具体的社会变化、公共行动或国家发展？它怎样改变孩子的选择，谁会受到影响？从总纲选一项价值，用这个选择及后果说明它如何体现社会主义核心价值观。区分总纲原词与本集的价值解读。只有公共议题进入因果、价值有具体行动支撑的主线可列首推；只适合做背景的材料说明缺哪一环。全是背景时如实说明本轮暂无主线首推。

拿不准主线和背景时，读[两次编剧现场判断](references/editorial-examples.md)。若编剧说「沿用上次的意见」，回到对应集的确认稿或会议记录，注明采用哪次决定。相互冲突的意见并列出处，向编剧确认后再沿用；本轮偏好只用于本轮。

联网时用现有网页检索工具找线索，用网页阅读工具读原文。对外查询只带公开主题、地点、活动和日期；作品大纲和内部记录用于本地判断。

## 主题菜单

1. 爱的教育（爱党、爱国、爱家、爱人）
2. 品德教育（向善、尊老爱幼、勤俭持家）
3. 成才教育（科学探索精神、好奇心、良好习惯、审美、创新意识和能力）
4. 健康教育（营养均衡、科学运动、睡眠充足、身心愉悦）
5. 生命教育（安全知识和技能、自我保护意识和能力、珍惜生命）
6. 劳动教育（正确的劳动观、生活自理能力、吃苦耐劳、热爱劳动）
7. 环保教育（热爱大自然，共生，互生）

## 主对话交稿

新闻选题开头给出主题、实际起止日期、目标条数与实际条数。 搜索结果用已核实的报道重新比较，在编剧选定范围内说明哪条热点最能以小见大、最能通过人物选择体现本集价值，给出对应子题和具体理由。默认交 10 条不同的已核选题（有合格主线时标出 1 条首推并说明理由，其余按适配度排序）；自选 N 条时首推计入 N，要求 1 条就只交首推。核实不足时如实报缺，不重复同一事件凑数。逐项按下列样式写，事实和虚构各占一段。

- **《拟题》｜主线或背景**
- **新闻依据**　近期发生的事、可核对的细节。（媒体或机构，日期，[报道原文]）
- **康家的戏（虚构）**　从哪个细节切入；小宁会问的原话和接下来的动作；谁和他想得不一样，为什么。这件事怎样落回所选主题？

- **以小见大与价值依据**　写清「孩子的小事 → 背后的公共议题 → 被改变的选择及后果」。附总纲章节及价值原词，再用一句话点明这如何体现本集的社会主义核心价值观。背景题注明欠缺处。典故的虚构选项也保留此栏。

若没有已核实的候选，先报检索范围和缺口，再列可追查的线索。收尾请编剧点选一个题或要求换一批；等选定后再进入故事类型或梗概。原案例的[首轮回话](<../../../docs/meetings/现场演示完整对话.md#q01>)可对照交稿粒度，新闻仍须核对原文。
