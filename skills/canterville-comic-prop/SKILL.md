# 坎特维尔喜剧道具

处理的问题是**让人物主动使用曾经嫌弃的道具**。从用户贴的原稿、指定的场次和想保住的人物选择开始。缺少原稿时，以用户提供的点子作一段标为原创的试写。

## 改稿步骤

1. 摘取暴露问题的原句，指出哪两处动作或信息之间缺少联系。读[原书依据与完整示范](references/research/source.md)，用一处书中动作或论点说明它和此稿的联系。
2. 钉死道具的实际功能。第一次记下是谁递来、接下会伤角色哪一点体面；第二次给他一个靠同一功能才能解决的问题。让观众先认出他的手伸向了哪里。
3. 在稿上做一次练习。让道具始终只有同一种功能。第一次由别人递上，写出主人公为什么丢脸；第二次改变他急需完成的事，让他亲手取用。用一个可见的小动作写出他让的那一步。
4. 先交修改的局部，再给一项作者可以立即做的复核。把为了示范新补的事实写明，尊重用户指定的结局。

## 本技能的工作表

第一次的提议及拒绝动作 → 新处境和新目标 → 第二次主动取用 → 他愿不愿被谁看见。

## 心智模型 · 读稿时要拆开的三件事

### 用途与冒犯

工具第一次就应有用，偏偏使用它会在某个人面前丢脸。两项缺一，后来取用的笑意都会弱。

### 处境与立场

改变角色想达到的目的，同样的功能就能从冒犯变成便利。让新目标先在场面里出现。

### 公开与私下

独自偷取、当众伸手、请对方帮忙，分别暴露不同程度的让步。局限是道具重现本身无法证明态度改变。

## 边界与适用条件

截至 2026-11-26，本包沿用项目已核实的中文书本采样。

- 如果物件第二次靠临时增加功能解围，喜剧转到了机关本身。要写人物让步，就保住同一种用途。
- 本稿的自拟台词、动作和结局应标注“原创试写”。
- 个人审稿口吻、未见版本或拍摄决定需要独立材料。

## 表达与张力

**这道练习的张力**　笑可以落在角色的窘迫，也可落在观众先认出旧物的时差。按人物此刻愿意被谁看见来挑。 描述时先说篇中谁做了什么，再给本次归纳的用法。
