## 哪些原集能回答编剧的问题

- **「大人说得对，可大人自己愿意付代价吗？」** 小新捡到钱，妈妈要他送交，一转眼特卖就要开始。对照小丸子的零花钱、《我们这一家》的便当、《新大头儿子和小头爸爸》的门口快递箱，能看到同一件事在孩子和大人眼里各值多少钱或多少时间。[东亚分集与原创练习](east-asia.md)
- **「哪一个动作让搭档改变主意？」** 《驯龙高手》终稿第 40 页可以看到小嗝嗝伸手后何时停下，最后一点距离由谁补上。《瑞克和莫蒂》第 206 集第 3 页适合看另一种动作：同一个决定如何让留下和离开的人各有一场戏。两份制作稿均有本地 PDF。[美国动画研究与离线制作稿](us-animation.md)
- **「一场戏盖住台词还能不能看懂？」** 《布鲁伊》的《Rain》可看大人如何用行动改变立场；《企鹅家族》的两处冰洞能让同一条鱼反复“上钩”。国际资料包含 10 个系列、16 个故事，以及 3 份可读的第三方分镜技能与两份博物馆练习材料。[国际喜剧卡与离线教学资料](international/README.md)

## 收藏的内容怎样计算

固定版本 GitHub 快照来自 **17 个仓库，分 25 个本地目录，345 个上游文件，其中 73 个文件名为 `SKILL.md`**。52 个入口来自角色包，48 个使用同一段「矛盾驱动」指引。灰太狼、懒羊羊、光头强、魔童哪吒四份有各自的写法。其余目录还包括字幕翻译上下文、插画提示、镜头案例、小说式儿童故事、短片与剧本工具。国际目录中以纯文字保存的另外 3 份分镜技能、博物馆材料和两份影视制作稿另计。[逐目录下载来源](sources.md) · [逐文件 Git 哈希](source-files.tsv)

- **原始编号覆盖。** 300 行已对照截图录入，其中 89 行有本地资料入口，涵盖同一系列的方法、角色卡、单集和地区调查等层次。40 项喜剧逐项列出来源或待核边界，保留小猪佩奇的译名复列、加菲猫与衍生系列的重叠。[300 项索引](catalog-300.md) · [40 项逐条说明](comedy-40.md)
- **材料用途。** `the-simpsons-context`、`rick-and-morty-context`、`futurama-context` 用于核口吻和译名。`spongebob-quote` 的查询依赖上游 CLI 与 Turso 服务，本地保存的是使用说明。`slapstick-art`、`kids-concept-creator`、`claymation-ad` 供视觉或制作参考。`kids-script-writer` 按短视频生产规格切镜，八秒的限制来自原工作流。[下载目录](sources.md)
- **使用状态。** 从项目目录按路径读取。已检查文件版本、哈希、正文和导航，未逐个运行上游技能或配置额外的斜杠命令。GitHub 片名检索曾遇到 403 限流，调查还使用了完整仓库树、播出平台、发行简介、主创访谈及社区分集资料。官网简介止于设问的地方，练习里的后续动作均为原创。[东亚检索记录](east-asia.md) · [美国检索记录](us-animation.md)
