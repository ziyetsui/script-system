# 国际动画编剧研究卡

遇到「这段戏只能靠角色说出来」时，可以先找一个相似的写作问题。比如同样写冰激凌，《Larva》让观众盯着下一滴会落在哪里；《Mr Bean》让观众看一个顾客怎样成了给别人服务的人。前者适合练道具和空间，后者适合练身份误认。

截至 2026-11-26，归档覆盖 **10 个系列、16 个不同故事**。七条指定旧线索全部核对，包含 5 张故事卡、1 张编导访谈卡、1 张制作报道卡。另有 11 张新增故事卡，其中 2 张来自新系列。材料按片名和版本计数，重复报道、教师指南、Skill 均不计入故事数。

## 可复制的研究与写作提示词

斜杠名称是本 README 的中文提示词标签。复制整句即可使用；配合离线文件时，将对应卡片附在同一轮。英文名链接到本地保存的公共 Skill 正文，以下三轮只用其文本方法。

| Skill 英文名 | 中文命令 | 提示词用法 |
|---|---|---|
| [animation](documents/animation/skill/source.txt) | `/拆规则` | `/拆规则` 阅读《Pingu Goes Fishing》和《Pingu & the Mix Up》中文卡。用两行分别写出角色以为发生了什么、实际发生了什么、哪件实物能揭晓。随后为原创题目「社区失物架上有两顶一样的帽子」提出一个不靠对白的误会，只写到误会成立，等我选定揭晓物。 |
| [shot-specifier](documents/shot-specifier/skill/source.txt) | `/排动作` | `/排动作` 已确定原创失物架故事用帽内姓名贴揭晓。写四格无对白分镜，每格写人物位置、手的动作、观众新知道的信息。让孩子和另一位失主都出现在第一格，末格要让双方看见姓名贴。只输出文本。 |
| [take-one](documents/take-one/skill/source.txt) | `/遮字审镜` | `/遮字审镜` 复查刚才的四格失物架分镜。假设姓名贴和所有字幕都被遮住，找出观众第一次无法解释角色判断的格子。只改这一格，用前面出现过的可见差异完成揭晓；给出改前、改后和一个盲读问题。 |

### 分轮示范

**第一轮**　冰钓时，Pingu 以为自己越钓越多，Robby 却使同一条鱼一再出现；揭晓物是被引出水面的 Robby。看蛋时，Pingu 以为找回了邻居的蛋，孵出的小企鹅才暴露错拿。原创提案：两人把一样的帽子放在失物架上，小孩先拿起靠自己的一顶。**确认点**　选帽内姓名贴来试第一版，并预留一个能从画面认出的细节。

**第二轮**　① 左侧小孩把自己的帽绳系成蝴蝶结，右侧来人把另一顶放在旁边。② 两帽滑到架子中央，小孩捡起没打结的那顶。③ 另一人伸手去拿有蝴蝶结的帽子，小孩回头。④ 两人把帽子翻过来，对照姓名贴，互换。**确认点**　第四格若看不清小字，还能知道为什么要换吗？

**第三轮**　改前靠读姓名贴。改后只换第四格：小孩摸到空绳头，又摸摸另一顶帽子上的蝴蝶结；对方顺着他的手看，两人同时递出帽子。盲读问题：「小孩摸到什么，才愿意把手里的帽子递出去？」这段帽子故事是练习原创。

## 核验边界

节目官网、播出平台、主创发言、报道和制作方供稿的性质逐卡标明。普通页面保留中文文字摘记，YouTube 只查公开标题和发布者，剧情另有同版梗概。保存了 2 份博物馆文档（1 份 PDF 原件、1 份纯文字）及 7 份仓库文本（3 份 Skill、1 份配套检查表、3 份许可证）。下载件分目录存放。具体页码、固定提交、PDF 校验值与未收录资料见[下载记录](craft-and-skills.md)。
