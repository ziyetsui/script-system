# 用《变身饼干》校准梗卡粒度

这是编剧提供的 few-shot。以下剧情依据示范文字，用于说明怎么把同一集的主梗、支线桥段和收尾用在不同写作卡点。

| 编剧卡在哪里 | 示范里的梗 | 换个故事怎样成立 |
| --- | --- | --- |
| 缺一个能让普通人闯祸的开局 | 错拿／错用。大雄把变身饼干当点心招待客人。 | 让同一件东西对主人有特殊用途，对旁人却像日用品。好客的人按自己的理解做件好事，麻烦就启动了。 |
| 人物可以慢慢解释，场面不急 | 倒计时。饼干吃下后隔一段时间才引发变化。 | 把后果设在一个角色来不及逃开、又来得及补救的时点，让每次补救都花掉时间。 |
| 角色知道真相，却没戏可演 | 瞒天过海。大雄和哆啦A梦知道会发生什么，客人和妈妈还蒙在鼓里。 | 安排两个都必须照顾的人，一个身上将出现破绽，一个最有机会看见它。 |
| 危机要延长，但人物一直在重复 | 调虎离山。上厕所、接电话、挽留客人，办法跟着客人的去留而变。 | 每次支开成功都改变当事人的下一步意图，迫使主角临场换招。 |
| 中段需要一场能独立演的小戏 | 恶作剧电话。客人被叫去接电话，电话那头还要他一直听下去。 | 先虚构一项必须亲自处理的事务，再让冒充办事的人和被骗者即兴周旋。它嵌在“支开客人”的大梗里。 |
| 冲突该收，却没人有资格叫停 | 长辈救场。爸爸回家，代孩子向妈妈道歉。 | 让来者具有承担后果或说服追责者的资格，给冲突双方一个下台阶。 |
| 事情解决得太干净，缺最后一拍 | 回旋镖。结尾有人说自己也吃了饼干，让先前的规则再生效一次。 | 保留已被观众理解的触发条件，把最后一次触发落到另一个当事人身上。 |

**调取时的尺度。** 编剧只问“怎么拖住客人”时，优先给调虎离山与假电话各自能演的动作。编剧问“结尾怎么翻”时，调用前面已经建立的饼干规则。正式三剧梗库里的每张卡都应由该剧自身的情节支持。
