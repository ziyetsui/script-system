# 编剧卡住时怎么调梗

把眼前那场戏贴出来，说清谁想干什么、哪一步写不下去，再点一部剧。每个 skill 都带已整理好的梗卡，可以直接借一个人物选择或一次局势变化。

| 眼前的问题 | 调哪套库 | 可复制提示词 |
| --- | --- | --- |
| 一家人都想帮忙，写出来却只有你一言我一语 | [《我爱我家》](../wo-ai-wo-jia-tropes/SKILL.md) | `/wo-ai-wo-jia-tropes 爷爷想帮儿媳保住面子，却越帮越忙。给我三种下一场，各写清他做了什么、谁误解了他。` |
| 两条线各自好笑，一剪到一起就散了 | [《摩登家庭》](../modern-family-tropes/SKILL.md) | `/modern-family-tropes 妈妈准备惊喜，儿子在瞒成绩。找能让两条线碰到一起的梗，保留妈妈最后才知道真相。` |
| 家长和孩子互不服气，结尾只剩讲道理 | [《成长的烦恼》](../growing-pains-tropes/SKILL.md) | `/growing-pains-tropes 爸爸认定孩子撒谎。找几个能让爸爸主动改口的梗，用行动收尾。` |

**第二轮**可以直接挑一条继续：“保留第二条的因果。人物换成姥姥和外孙，场地只能在社区食堂，给我三个能演的节拍。最后一个决定由外孙来做。”

**跨剧找。** 可以直接说：“从三套梗库里找三种帮倒忙，分别要越瞒越糟、误会错人、好心反噬。每种给原剧出处和适合我这场戏的改法。”本地命令从项目入口目录运行，结果保留剧集、原文短引和可迁移公式。

```sh
python3 剧本系统/skills/trope-library/trope-library.py all 误会 帮忙 --limit 8
```

梗卡的取舍尺度见[《变身饼干》示范](trope-library-fewshot.md)。更新梗库后可以运行 `python3 剧本系统/skills/trope-library/check-trope-library.py` 检查每张卡的原文短引。
