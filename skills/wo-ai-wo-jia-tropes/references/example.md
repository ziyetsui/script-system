# 同是「越劝越来劲」，卡点不同，选卡也不同

用户拿《哆啦A梦》的动物饼干举例时，可以把「误拿道具 → 效果倒计时 → 遮掩异状 → 打电话支开人 → 麻烦回到自己身上」当作拆解粒度的示意。下面两张《我爱我家》梗卡各自只保留原集真正推动情节的动作。

**卡点一：想让孩子主动放弃，怎么把家人写成帮她的人？**

第 021 集《女儿要远航》00:05:01–00:13:52。圆圆想出海，一家人约好教她枯燥的知识，让她知难而退。可一到自己擅长的科目，人人都想证明自己教得好。家人再开会，教潜艇的得意地说她连参数都背得比自己溜，已经没人知道下一课拿什么难住她。回查短引「一个一个比比一个会教书」。[本地转写](<../../../../docs/materials/videos/《我爱我家》全集音频剪辑/「021」女儿要远航.md>)

**可迁移的写法**：让阻拦者以训练为借口设门槛。给每个老师一个比「挡住孩子」更贴身的愿望，比如不能让外行学错自家手艺。孩子每开一个窍，拦她的人都有一份功劳。

**卡点二：大家都夸偶像，怎么让揭短的人也帮他加分？**

第 025 集《爱你再商量》00:16:04–00:19:46。家人请孟老师配合，让小凡听听他学生时代的黑历史。众人提起教室里的旧标语，老师顺势认下；一问标语的内容和年代，小凡认定他比别人更早看清形势。回查短引「揭发会可就该表扬会了」。[本地转写](<../../../../docs/materials/videos/《我爱我家》全集音频剪辑/「025」爱你再商量.md>)

**可迁移的写法**：保留同一件事实，换听者衡量它的标准。第 021 集里，阻拦者亲手教会了孩子；第 025 集里，阻拦者提供的证据被孩子读出了相反的意思。

**改编到新戏**：阿婆想让外孙放弃学修收音机。若走第 021 集这一条，她故意让孩子从最难辨的杂音听起，却忍不住一次次纠正他的手法；下午有顾客进门，孩子听一耳就找对了毛病。若走第 025 集这一条，她讲起师傅曾为一台旧机器倒贴三天工钱，拿来劝孩子别入行；孩子打听出了客户是独居老人，问的第一句却是「那位师傅还收徒吗？」
