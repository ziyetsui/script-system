# 水浒传风格 写作风格 Skill

本 Skill 由 **human-writing-distill** 项目通过大模型蒸馏生成，非统计脚本提取。

## 模型信息

- HuggingFace: `stylellm/ShuiHuZhuan-6b`
- 蒸馏方法: StyleLLM（SFT + 可选 PPO），参考 [stylellm/stylellm_models](https://github.com/stylellm/stylellm_models)
- 生成时间: 2026-07-09 01:31 UTC

## 风格特征（模型习得）

StyleLLM 模型从全书学习了以下维度，改写时自动体现：
- **用词**: 惯用词汇、成语密度、人物称谓
- **句式**: 句长节奏、对话结构、修辞手法
- **语感**: 叙事口吻、段落组织

## 风格迁移示例

### 示例 1
- **原文**: 严冬时节，鹅毛一样的大雪片在天空中到处飞舞着，有一个王后坐在王宫里的一扇窗子边，正在为她的女儿做针线活儿，寒风卷着雪片飘进了窗子，乌木窗台上飘落了不少雪花。
- **风格化**: 此时正是隆冬之际，鹅毛般大雪乱飘，有一王后坐于王宫内一扇窗户前，正缝其女衣，寒风卷雪入得窗来，把那乌木窗台都压坏了。

### 示例 2
- **原文**: 她抬头向窗外望去，一不留神，针刺进了她的手指，红红的鲜血从针口流了出来，有三点血滴落在飘进窗子的雪花上。
- **风格化**: 那娘子仰面看时，只道是雪片落将下来，不提防把针儿捻在手里，一时失手，正中指尖，便见出血来，有三两点，都滴入窗里去。


## Agent 写作指南

1. **优先模仿上述示例的语感**，而非套用 AI 套话（「综上所述」「值得注意的是」）
2. 用户给出草稿时，按示例中的改写幅度进行风格化（保持原意，变换措辞与句式）
3. 需要精确风格迁移时，调用蒸馏项目推理:

```bash
cd human-writing-distill
python scripts/infer.py --style shuihu --text "你的原文"
```

4. 长文写作：分段改写，每段保持风格一致
