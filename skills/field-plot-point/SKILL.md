# 菲尔德情节点

处理的问题是**消息怎样改变主角的下一项任务**。从用户贴的原稿、指定的场次和想保住的人物选择开始。缺少原稿时，以用户提供的点子作一段标为原创的试写。

## 改稿步骤

1. 摘取暴露问题的原句，指出哪两处动作或信息之间缺少联系。读[原书依据与完整示范](references/research/source.md)，用一处书中动作或论点说明它和此稿的联系。
2. 把相邻两场各压成“谁＋动词＋对象”。圈出使旧任务失效的新事实。给主角写出一个此刻能着手的新任务，并补一句为什么必须由这个人行动。
3. 在稿上做一次练习。写两张卡，每张只留“主角＋动词＋对象”。中间填入消息，再划掉一个因消息而失效的做法。如果两张都写“继续寻找”，让主角用已知事实采取另一项可执行的行动。
4. 先交修改的局部，再给一项作者可以立即做的复核。把为了示范新补的事实写明，尊重用户指定的结局。

## 本技能的工作表

前一场的行动 → 新事实 → 原办法为何失效 → 下一场开头的可见行动。划掉新事实试读一次。

## 心智模型 · 读稿时要拆开的三件事

### 事与行动

观众知道了一个秘密，主角却可能一无所知。分别写观众知道什么和主角能用什么。

### 方向与强度

把“更着急地找”换成动词测试，看看调查是否真正转为营救、掩护或对质。

### 因果与巧合

巧遇可以启动事件。局限在于巧遇本身不会替主角决定下一步，仍要交代选择。

## 边界与适用条件

截至 2026-11-26，本包沿用项目已核实的中文书本采样。

- 悬疑线索可以只增加压力。若作者有意让搜索继续，先指出转向发生在后面哪一场，不必强迫每条线索都担当情节点。
- 本稿的自拟台词、动作和结局应标注“原创试写”。
- 个人审稿口吻、未见版本或拍摄决定需要独立材料。

## 表达与张力

**这道练习的张力**　转折太早，前面的目标尚未立住；交代太晚，观众已经不懂主角为何动身。试把新信息移到第一次需要它的位置。 转述书中的概念时注明书名，把本次设计的检验办法单列。
