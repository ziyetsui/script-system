# 菲尔德情节点 · 试用记录

2026-11-26。独立答题者只读本技能及包内参考，实际完成一题。

## 试题

自拟原稿：主持人在空礼堂给迟到的决赛选手打电话。收到全队合照后，她接着逐个拨号。要保留准时开赛。

## 实际改写

原创练习。主持人刚拨到第三个号码，屏幕上跳出一张合照。十二个孩子挤在礼堂侧门的玻璃后，举着她寄的请柬，上面写的正是侧门。她扭头，看见玻璃那一边也有十二只手在挥。下一场，她解下腰间唯一的侧门钥匙，把门敞到头，领队的孩子踩着开场铃上台。

## 怎样复核

两张卡分别是「主持人催选手到场」「主持人开门接全队」。新增的照片证明十二人已经到场，催人赶路这招失效；钥匙解释了为何她须亲自行动。遮去照片和随之发生的目击，拨到第三个号码时她仍不知另九人在哪儿。

包内《电影剧本写作基础》915–917行以调查者取得证据说明进行中的行动如何转向。两张卡是编辑练习。
