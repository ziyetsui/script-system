# 摩登家庭梗库

## 编剧卡住时

1. 从用户的场面里找出「谁想做什么，哪一步走不下去」。拿动作和关系去查已拆好的 [梗卡](cards.jsonl)。从 intake 根目录运行，例如 `python3 剧本系统/skills/trope-library/trope-library.py modern-family 两条线 并线 道具 --limit 8`。可换「道歉 反悔」「父亲 立威」「聚餐 秘密」等短词。工具按命中词数排序；若只有道具或人物碰巧相同，换触发动词或后果重查。
2. 逐张读 `beat` 和 `formula`，只留能推动用户眼前这一步的写法。跨集查询先按集号和因果去重，再比较**谁先知道、谁做了什么、代价落给谁**。候选少就照实给；若用户指定集号，严格过滤 `episode`，工具的多词查询会同时返回只命中其一的记录。
3. 每个候选用「梗名＋集号 → 原剧怎样转 → 为什么适合眼前的卡点」回答。附一条逐字 `anchor`，按需给出 `docs/materials/videos/` 加 `source` 的路径。用户要试写时，用他的人物、关系和限制替换变量，明确标「套用」；当轮给出可演的动作和落点。有明确偏好就直接展开。

## 指定集或继续补拆

- **查本集已收录梗。** 运行 `python3 剧本系统/skills/trope-library/trope-library.py modern-family S01E01 --limit 100`。分别列举不同人物线与交会点，把同一链条的铺垫和回收放在一起。只有逐场核查过的范围才能称为「整集复核」。
- **要完整拆某集、查漏或核实新线索。** 从一张卡的 `source` 打开整份正片稿。无卡时先在 `docs/materials/videos/M_摩DJ庭_1080P/` 下找视频对应稿，核对目录季号、文件名和稿首原剧本名。第七季用 `S07/01.md` 这样的文件名；大结局两集同卷。只在正片稿缺失或不清时对照原音音频稿。按集号和对白正文排重，排除纪录片、花絮、删减段落和《摩登告别》。无时间码时给原句或行号。
- 从片头读至片尾，含访谈和尾声。先按每户、每对人物或共同事件记录「起意 → 行动 → 对方如何理解或回应 → 谁受了什么后果」，交叉剪辑处仍接回原人物线。逐场复查：有没有独立的小反转？有没有一线的物件、消息或人**直接改变**另一线行动？能删去它而结局照旧的相似台词或同步剪辑，只作呼应。
- 能用换人换物后的动作复演、有可定位的起点和结果，就形成一张卡。连续加码共用同一回收时合为一张；同一事件若另有独立选择与后果，可以另列。找出每个箭头的前后台词或动作，再从转折处摘逐字短引；画外经过若只有暗示便标出。材料缺页、找不到回收或多个版本无法对应，列明缺口。
- 用户要扩库时，每行写入 `episode / source / anchor / trope / block / beat / formula`。`source` 相对 `docs/materials/videos/`；`block` 用编剧会问的卡点，`beat` 说本集人物与因果，`formula` 写可迁移动作。先搜索原字段排重，再验证 `anchor in 原稿全文`。无需给每集凑齐固定数量或同一套类型。
