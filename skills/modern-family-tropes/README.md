## 分两轮使用

**第一轮 · 选机制**

> /摩登家庭梗库 我写社区排练，后台修道具、前台考新导演，两条线怎么并线？找一张有实物交接或残留痕迹的梗卡，给我集号、原句和可以借走的动作。

示范回答：**S01E01〈给孩子解围的道具放倒家长〉**。卢克的头卡进栏杆，家人要拿婴儿油。另一边，菲尔想震住女儿的男友，留下的油却把自己滑倒，他得请男孩帮忙。可以借走的是「甲线用某物解决了问题 → 东西的痕迹留在现场 → 乙线本来要考别人，看走眼后反而要向对方求助」。原句是「我被婴儿油滑倒了」。[原稿 L1078](../../../docs/materials/videos/M_摩DJ庭_1080P/摩DJ庭_全11季视频1080P_中英双字/S01/S01E01%201080p%20BluRay.md#L1078)

**确认点**：这次要保留的是“修好的东西留下痕迹”和“考官反过来求人”。第二轮可以指定想保留的动作，并补充现场限制。

**第二轮 · 套进自己的场面**

> /摩登家庭梗库 就用婴儿油那张。我的主角是社区剧团老团长，想当众考新导演。后台只有纸胶带，演员不能摔倒。写三个连续动作，让新导演凭本事帮他收场。

示范回答（原创套用）：后台把纸月亮裂开的支架粘牢，胶带的余端贴到了旁边的黑幕。老团长请观众给“最圆的月亮”投票，自己一拉幕，月亮被拖得翻过去，只剩窄窄的侧影。新导演没有喊停，让演月亮的小孩接一句“今天才初三”，又示意后台慢慢转回正面；老团长只好接过他递来的话头，带全场数到十五，月亮正好转圆。
