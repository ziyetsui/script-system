# 单集怎样拆到可复用的粒度

| 邓菲家，家法 | 卢克拿塑料枪误伤姐姐；爸妈和孩子对日程排出受罚时间，孩子层层加衣。父亲说自己下不了手，后来仍误伤了人。 | 把气头上的处罚精确预约，给双方时间准备；等执行者宣布收手再回收道具。「4点15吧」L594，误伤见 L1494、1674。 |

| 晚餐，宝宝亮相 | 杰把小卡的缺席读成分手；米奇尔还在驳斥小卡爱小题大做的评价，小卡已伴着音乐抱宝宝出场。 | 把缺席者的辩词交给旁人，再让入场方式亲自作证。「他才没有小题大做」L1774，「我是说音乐」L1794。 |
| 晚餐，杰改口 | 杰先认为领养是坏主意，见到莉莉后承认自己也犯过错；他借来刚才听不懂的西语谚语，笨拙地向儿子表达支持。 | 把听来的话交给原本最抗拒的人；复述仍拗口，使用目的已经变了。「你只可背后送春风」L1230 →「吹吹后背春风的」L1866。 |
| 尾声，情诗 | 家人聚齐后，关于爱和不同世界的诗听来像在说全家；最后念出布兰达的名字，把它收回成曼尼写给姑娘的诗。 | 让文字同时适合两个对象，只把真正的收件人留到末尾。「我的心只属于你」L1930，「布兰达·费尔曼」L1934。 |
| 尾声，父子篮球 | 菲尔大谈将来卢克若赢球，自己必会大方夸奖；想了想又给比赛追加一条规则。 | 让嘴上开明的人把场面想到底，等他自己说出想把胜利拿回来的条件。「三局两胜才算赢」L1990。 |

卢克穿几条内裤、家人查行程、菲尔到点心软，各自能逗笑观众，却都在兑现同一条家法。婴儿油则既处理栏杆问题，又直接改变另一场见面里的强弱关系，所以另收一张并线卡。

## 动作链练习

以《哆啦A梦》动物饼干的讲法示意拆法：拿错东西让人吃下饼干 → 等待动物变化的时限迫近 → 为了遮住变化开始瞒人 → 用一通电话把对方的注意力支走 → 暂时奏效的转移又把麻烦弹回自己。可借走的是「误用造成限时后果，掩饰需要借力，借来的力又反弹」这条链。它是粒度练习；本剧每张卡的段数随原剧情而定。
