# 莫泊桑误判的原书依据

## 来源与定位

《莫泊桑主题小说选·全5册》。以下行号按项目所供中文 Markdown 转写本，从 1 起计。

《珠宝》篇名见第16269行。朗丹估亡妻的项链只值六到八法郎，珠宝商报出高价并查到送货记录，他开始疑心礼物的来处（第16309、16321、16347–16357行）。《项链》是另一篇，篇名见第18289行。夫妇买真项链赔还，十年还清债，原主这才说借出的是假货（第18473–18479、18495–18497、18545行）。

引用时写“从这段情节可观察到”。练习和改稿为编辑提炼；译本措辞不可当成作者亲授公式。 范围限于所列段落。若问作者是否会批准这份稿，指出目前材料能支持的具体文本判断。

## 原创示范

**改前**　店主要清仓，最后一页才知道那张戏单值很多钱。

**改后**　低估版：店主见戏单上画满铅笔人像，把它当涂鸦纸裁成价签。散场后来取画的老演员从柜台上拈起半张脸：“我们首演那晚，她给每个人都画了一张。”另外几半已经随货卖走了。高估版：店主弄丢了借展的戏单，以为是签名原件，赶在散场前拿当月房租向收藏商买了一张同版签名戏单赔还。出借人翻到背面找复印店的蓝章，这才知道他买的是真迹。收藏商的摊子已经撤了。

**拿掉一处再读**　真相提早一天说破，哪项损失本可挽回？两版的误判各是谁的，写在哪个动作里？
