# 莫泊桑误判

处理的问题是**人物因估错价值而付出代价**。从用户贴的原稿、指定的场次和想保住的人物选择开始。缺少原稿时，以用户提供的点子作一段标为原创的试写。

## 改稿步骤

1. 摘取暴露问题的原句，指出哪两处动作或信息之间缺少联系。读[原书依据与完整示范](references/research/source.md)，用一处书中动作或论点说明它和此稿的联系。
2. 固定同一件东西。先把揭晓遮住，问此刻什么证据足以让人物相信自己的估价。高估版让人物按高价赔付、典当或承诺；低估版让人物送走、耗用或轻率舍弃。最后才揭晓确切价值或来历。
3. 在稿上做一次练习。给同一物件各写一条低估和高估的因果链。两条都依次填上谁估价、为什么信、据此做了什么、真相揭晓时谁已无法追回什么。选一条，把揭晓放在行动之后。
4. 先交修改的局部，再给一项作者可以立即做的复核。把为了示范新补的事实写明，尊重用户指定的结局。

## 本技能的工作表

谁误判／凭什么信／怎样按错价行动／何时得知真相／哪一项已经拿不回来。各用一行列账，再写成短场。

## 心智模型 · 读稿时要拆开的三件事

### 价格与相信的价格

先单独记真相，再盖住它。寻找当事人在当时有理由采信的外观、来历或他人的一句话。

### 相信与付出

误判必须先进入一个动作。为假货承担真价和把珍品当废物处理，会产生不同的损失。

### 揭晓与可逆性

写下揭晓时还能拿给观众看的一件证物。东西已烧毁或剪碎，就查还有哪一部分留着，凭哪个细节足以辨认真伪。再问人物付钱或动手前能不能当场查清。揭晓后马上能原价取回时，损失还很轻。局限是喜剧也可保留挽回的机会，但要付出某种代价。

## 边界与适用条件

截至 2026-11-26，本包沿用项目已核实的中文书本采样。

- 真伪、市场价格、私人意义可以不同。写感情价值时先交代谁珍惜它；单靠报出惊人市价很难补上前面缺少的行动。
- 本稿的自拟台词、动作和结局应标注“原创试写”。
- 个人审稿口吻、未见版本或拍摄决定需要独立材料。

## 表达与张力

**这道练习的张力**　多埋一条线索能使真相可信，也可能让误判显得愚蠢。把线索分别放到读者和人物当时的知情范围中检验。 描述时先说篇中谁做了什么，再给本次归纳的用法。
