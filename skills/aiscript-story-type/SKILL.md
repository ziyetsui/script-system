# 给已选的故事挑类型

1. **先核对本集要保留什么。** 读 `$ARGUMENTS` 和编剧确认的本集材料，把必须保留的冲突写成一句话。只有“诚信”这类主题词而没有处境时，问“谁对谁做了什么，让这件事难办？”已有冲突就能开始，集名可留空。
2. **找到能承担选择的人。** 写清谁看见事情发生，谁在高潮为一个决定付代价；这两人可以不同。编剧尚未定主角时，把可行人选作为改编假设来比较。为《北京一家人》选型时，先读[创作大纲](../../docs/harness/北京一家人-创作大纲-520集.md)中儿童主视角、双主角与相关人物的段落，说明观众怎样跟着孩子经历这件事。
3. **按这集难写的地方挑讲法。** 若编剧限定“只从某体系里选”，遵守这个范围。开放选型时，至少拿两种不同体系的讲法对照，把同一个内核各推演一次。想找贯穿全剧的冲突，可以看[《救猫咪》十种故事类型](../../../剧本系统/docs/reference/通用-救猫咪10种故事类型.md)；想安排事件的先后和转折，看[菲尔德三幕式、麦基危机与高潮、起承转合等](../sw-story-structure/SKILL.md)；想让人物的弱点与计划生出情节，看[特鲁比七步](../sw-truby-anatomy/SKILL.md)；想让每次补救都把局面弄得更糟，看[情景喜剧七步法](../sw-sitcom-comedy/SKILL.md)；已有结尾动作，可用[阿恩特的结局倒推法](../screenwriter-michael-arndt/SKILL.md)。这些是可查的起点，编剧提出其他经典模型时核对其定义再比较。

   用同一组问题检验候选：跟着谁看？第一次行动怎样引出下一场麻烦？高潮谁作决定，代价是什么？推荐最贴合本集的一版，并写出另一版会改变的具体情节。故事类型描述核心冲突，戏剧结构安排冲突怎样发展；如果两者可以合用，说清各自负责什么。两个标签会写出同一版剧情时，合为一个方案。
4. **处理分歧。** 分开写编剧已确认的要求、项目资料原话和本轮改编设想。材料冲突到会改变选型时，并列两处出处，说明各自导向什么，问编剧需要决定的那一个问题。材料打不开时标明缺哪一份；先给能由现有材料支撑的条件判断，保留无法核实的部分。

## 交给编剧

- **保留的内核**　一句话。
- **推荐讲法及理由**　标明所用的故事类型、戏剧结构或两者的组合。交代跟谁看、谁作决定，用开头、转折和高潮的具体动作解释为什么适合；备选写出换一种讲法后的剧情差异。
- **范围核对**　开放选型的答复中写明每版所属体系，并各附一处模型出处。若两版都取自同一张类型表，交稿前换一个戏剧结构重新推演，例如把关系误会分别按“伙伴之情”和“情景喜剧七步法”写到高潮。如果跨体系推演后决定合用，写明两种方法各自带来的具体动作。明确限定单一体系时跳过此项。
- **依据和待选项**　标出本轮输入里的关键原话，附实际读过的文件链接及段落或行号。把本轮新增动作标为改编建议。交稿前遮住类型名读一遍：编剧能否仅凭人物动作区分两版？

本轮停在选型建议，保留每版的主角与高潮，方便编剧点选。可参照[《奶奶的约会》第 3 问](../../../docs/meetings/现场演示完整对话.md#q03)。

## 编剧选定后写大纲

若任务包含“等我选完再写大纲”，只有编剧明确选中一版（如“选第二版”“就写小宁做决定的那版”），才沿用该版的内核、主角、高潮选择和必留细节，按[单集短大纲](../../../../../.claude/skills/aiscript-short-outline/SKILL.md)交付起、承、转、合。开场的行动引出阻碍，补救造成转折，高潮保留选定人物亲自作出的决定，结尾写出代价和后果。若“这版”能指向两个方案，只问指哪一版。编剧已选且要求完整大纲时，在当前回复写完。
