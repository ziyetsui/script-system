按任务查用法

从上面三项高频示例开始，或点下表跳到手上的任务。打开同时包含 skills/、agents/、automations/ 的仓库根目录，在 Codex、Claude Code 或 Cursor 的对话中复制一项的第一句。收到答复后，按“判断”选定要保留的动作，再单独复制第二句。输入里提到的上版稿、热点卡、原作片段要一同贴上。

同名的岗位和技能分开列。例如独立卡在一场戏时用“找梗”技能，整集协作时将带编号的候选交给“找梗”岗位。群策 和 swarm 共用分派规则。首轮产物栏写的是该提示要求交回的东西；标有“历史答卷”的链接可以检查当时实际交到哪里。第二句供编剧按当前答复调整。
