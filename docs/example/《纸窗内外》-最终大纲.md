# 《纸窗内外》｜完整剧本大纲

康小宁原本想在科普展上讲「我家的墙是怎么裂的」。一扇纸窗让他发现，一张照片说不清一面墙是怎么裂的。也是这扇纸窗，让他顺着一张旧车票，看到一个孩子是怎么被一双双手接到家的。

## 起｜我家的墙是怎么裂的

学校科普展彩排。康小宁抢到了第一个上台的位置，连主持卡都印好了。他把自家院墙上的一道斜缝放大贴在展板上，还做了个滑坡模型，准备当众一拉拉片，让大家看见坡土是怎么把墙推裂的。

招财童子问：「你怎么知道，当时就是这么裂的？」

小宁指着展板：「你看，照片跟我的模型一模一样。」

童子从废展板上剪了一个方孔，轮流挡在两个模型前。隔着纸窗，小宁看到的都是同样一道斜线。纸板拿开，他才看见一条是画在整块板上的，另一条是两块板之间的缝。他一推，右边的两块板错开了，左边那条线原封不动。

轮到小宁试讲，童子的手已经捏住拉片。小宁看看模型，又看看照片。那张特写里只有一道缝，连墙根外面是什么样都看不见。他把印好的主持卡扣在桌上。

「老师，开场先给下一组吧。我得回家再看看。」

## 承｜列车还没到，但是到家了

回家后，小宁拉开抽屉，想把模型收起来。模型底座顶到一本旧相册。他把相册抽出来，一张照片从封底滑到了桌上。

还是那面墙，还是那道斜缝。照片边上多出来的那一截里，坐着一个从没见过的男孩。男孩裹着一床黄被子，被角露出一只绣歪的小船。小宁一眼就认出来，那是自己小时候央爷爷绣的。

「爷爷，他怎么盖着我的被子？」

爷爷戴上老花镜看了一会儿。「那年下大雨。这是他临走前留下的。里头还有一样东西，你看看。」

小宁从相册封底的纸袋里抽出一张旧车票。**K396，终点北京丰台。** 他原本只想查查，那个盖过自己被子的孩子后来去了哪儿。车次和日期刚输进去，搜索结果最上面就跳出一条新闻。

**《列车还没到，但是到家了》**

「到哪儿了？」小宁和童子同时开口，两个人对看一眼。

小宁点进去。报道说，那趟列车在暴雨中停在了落坡岭。附近居民腾出地方安置乘客，后来救援人员接应转运。小宁又看了一眼照片。

「那这个孩子呢？他跟着谁走的？」

童子捡起他们从学校带回来的那扇纸窗，朝小宁伸手。

「车票给我。咱们跟着他看。」

## 转｜把纸窗往旁边挪一点

童子用金手镯一碰胸前的吉祥金锁。金锁「咔哒」一声弹开，四个金角沿着方孔伸展，把软塌塌的纸板撑成一扇小窗。窗底弹出两只夹子。童子夹上车票，票面上的 **K396** 亮了一下。方孔里原本是自家的院墙，眨眼间，墙没了，一扇淌水的车窗顶了上来。

小宁吓得放下纸窗。院子里静悄悄的。他再举起来，雨点又劈里啪啦地砸在玻璃上。男孩正把车票塞进口袋，票角上那道折痕，跟夹在窗底的那张一模一样。男孩往前走，窗里的画面也跟着往前走。

车厢另一头有人喊：「往里传！」

小宁把纸窗朝声音那边一挪。男孩出了画，一只手从车门口伸进来。吃的从一双手传到下一双手，一直传进车厢深处。小宁把窗挪回来，正看见男孩掰开手里的面包，把一半递给旁边更小的孩子。

后来，男孩跟着大人下了车，在一扇亮着灯的门前停住。小宁以为到了。可开门的人往屋里看了一眼，转身就跑。

「他去哪儿？」小宁赶紧把窗往旁边挪。方孔扫过满屋坐着的人，又越过一道墙，刚好追上那人在敲对面的门。对面很快开了，有人抱着刚从床上卷起来的被子，侧身让开。

「孩子先进来。」

等到救援人员来接，男孩走出几步，又跑回去，把自己坐过的小凳子推到墙边，给后面的人腾出路。过积水时，有人扶住他的胳膊。上车时，又有一只手从车门里伸出来，把他拉了上去。

纸窗最后亮起来，照出一间屋子。男孩坐在门槛边，鞋尖还沾着泥。有人从半开的门里抱出一床黄被子，盖到他肩上。小宁把纸窗再往上一抬，想看看这是谁家。门牌还没进画面，男孩先伸手攥住了被角。

那只绣歪的小船露了出来。接着，纸窗暗了。

「所以，他最后到底到哪儿了？」小宁还举着那扇空了的窗。

童子没说话，把桌上的旧照片往他手边挪了挪。小宁看着照片里那个攥住被角的男孩，手指捏住了卷起来的一角。

## 合｜小康家

切到科普展。小宁的手还捏着那个照片角。他把整张旧照贴上展板，盖住原先那张只拍到墙缝的特写。

「我家的墙是怎么裂的，我还没弄清楚。」他举起纸窗，先框住墙缝，再把窗慢慢移到男孩身上。「我今天想讲讲，这个孩子是怎么到家的。」

小宁从那条新闻讲起。讲到亮着灯的第一扇门时，他停了一下，把纸窗往旁边挪了挪，讲起那个跑去敲对面门的人。讲到最后，他把纸窗拿开，台下的人终于看见了整张照片。

童子从展板边探出头，小声接上他们读到新闻时的那句话。

「那他最后，到哪儿了？」

小宁把照片翻过来，递到他眼前。

「你自己看。」

照片背面，有三个歪歪扭扭的字。

**小康家。**
