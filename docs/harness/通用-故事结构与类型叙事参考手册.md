# 一 概念总览与方法分工

## 六个层面怎样配合

**类型：**观众主要期待什么体验，如爱情的亲密与阻隔、恐怖的安全感破坏、悬疑的真相追问。

**情节路径：**人物经历什么过程，如寻找、复仇、逃亡、调查、崛起与衰落。

**整体结构：**事件怎样形成开端、发展、转折与收束。三幕式与起承转合主要在这一层发挥作用，但划分依据并不完全相同。

**事件功能：**一个动作在全篇中起什么作用。普罗普关心“考验”“获赠”“识别”等结构关系。

**叙述方式：**事件以什么顺序、视角、时间尺度呈现。倒叙、多线、回忆框架等属于这一层。

**叙事质感：**故事如何与现实、记忆、自然、礼俗建立联系。“传说感”主要涉及这一层，也会反过来影响情节与结尾。

同一事件可以在多个层面被理解。例如“少年给老人半块饼”：它可以位于第二幕，是一次赠予者考验，属于寻访旅程的一站，也可以在结尾的回忆中才被讲出。

## 不应混淆的关系

三幕式不是外国故事的本质，起承转合也不是中国故事的统一公式。中国神话、史传、志怪、章回小说、戏曲存在不同传统；外国也有史诗、童话、地方传说等多种组织方式。

类型边界具有历史性与交叉性。“动画”首先是表现形式，“合家欢”主要界定受众，“剧情片”是宽泛标签，“艺术电影”不能等同没有情节。

一个故事可以混合多种类型。选择主类型，是为了明确最主要的观看期待与高潮问题，而非禁止交叉。

# 二 三幕式与起承转合

## 三幕式

**基本路径：**原有生活 → 事件促使人物行动 → 目标与阻碍持续交锋 → 关键选择与行动 → 结果及余波。

**第一幕 开端与建置：**建立人物、环境、欲望、风险与主要矛盾，使行动真正开始。检查：他要什么？为什么现在必须行动？

**第二幕 中段与对抗：**人物尝试解决问题，阻力与代价升级，旧方法逐渐失效。对抗对象可以是敌人、自然、制度、关系或内心恐惧。

**第三幕 结尾与结局：**人物以关键选择和最终行动回应主要冲突，交代获得、失去与改变。结局可以成功、失败、悲喜交织或保留余问。

三幕不等于三等分，也不要求固定分钟数。重要的是阶段之间有因果推动，人物不能用同一种方法反复解决同一种困难。

**示例：**孩子得知乡村戏台要关闭，决定办演出 → 找人筹物不断碰壁，临演主角退出 → 孩子克服怯场登台，戏台命运与孩子变化得到交代。

## 起承转合

**基本路径：**提出情境 → 承接展开 → 方向或认识发生变化 → 收束并回应前文。

**起：**引入人物、事件、画面或情绪，建立值得继续讲述的局面。

**承：**发展关系与事件，积累矛盾和情感。它不是无事发生的过渡段。

**转：**改变处境、行动方向、情感或理解。可以是外部变故，也可以是人物终于看懂此前的事情。

**合：**使事件、情感或主题形成回应，不必大团圆，也不等于把所有疑问解释完。

**同一示例：**孩子想保住奶奶唱过戏的戏台 → 四处筹演却发现奶奶不愿参加 → 理解她真正怀念的是昔日伙伴 → 找回伙伴，让“留下什么”得到回答。

## 两者的区别与结合

**三幕式主要问：**行动如何开始、受阻和得到结果？起承转合主要问：叙述如何引出、展开、转向和收束？

三幕式同样包含多个转折；起与承同样可以充满冲突。“转”可在第二幕中间、末尾或更晚发生，不能固定等同第三幕。

**常用对应只是参考：**第一幕可承担起，第二幕可承担承及重要的转，第三幕承担转折后的最终行动与合。

**双重检查：**人物最终做了什么导致结果？结尾又怎样回应开头提出的情感或意义？

# 三 中国传统叙事与传说感

## 比较的正确尺度

以行动因果为中心的戏剧常问“人物如何实现目标”；神话传说还常问“世界为什么如此，人们为何记住此事”。这是两种倾向，而不是中西文化的绝对界线。

神话往往涉及神圣起源、宇宙秩序及人与超越力量的关系；传说常与特定人物、地方、遗迹及某种被讲述者相信的过去关联；神奇故事则可以更自由地讲述虚构冒险。三者会交叉，但不能完全等同。

上古神话常以古籍中的短片段保存。文本简略不代表古人当初的完整口头讲述也必然简略。

## 值得借鉴的叙事特点

**让人的遭遇留在自然中：**人物化为鸟、石、树，或留下河流与山岭。夸父的行动结束后，手杖化为邓林；人物通过世界继续存在。

**让情感获得可见的形状：**悲恸、誓愿、冤屈通过天地异变显现。孟姜女哭崩长城，把私人悲痛扩大为可感知的外部力量。神迹须承接此前的情感积累。

**以平静口吻讲奇事：**地点、物件、习俗具体，超自然机制解释克制。细节的日常性使奇异具有传闻和见证的质感。

**围绕地方聚集故事：**一条河、一座庙可连接不同人物和年代，形成故事群，而非始终依赖同一个主角。

**允许行动未完成而形象已完成：**精卫并不需要最终填平大海，持续衔石本身就能构成完整而有力的形象。

## 五种实用路径

**起源型：**原有缺失或混乱 → 神异行动 → 世界形成新的样貌。重心是“为何如此”。

**变形型：**极端遭遇 → 化为异类或自然之物 → 愿望继续存在。重心是“什么仍在延续”。

**禁忌型：**建立规则 → 遵守或触犯 → 后果 → 留下禁忌。重心是“边界为何重要”。

**遗迹型：**非常行动 → 人物离去 → 留下地貌、器物或地名。重心是“这里为何如此”。

**感应型：**情感或行动达到极致 → 天地或神灵回应 → 命运与秩序改变。重心是“什么值得回应”。

## 写出传说感的五个动作

**先寻找今天仍存在的东西：**井、鸟叫、灯、地名、节日、村规。可以由遗存往回构思。

**把愿望凝聚为可重复的动作：**等人、守灯、衔石、种树。动作比抽象品质更容易被记住。

**让神异变化承接人物行动：**守水者成为泉源，等待者成为望向远方的石头，变化需要内在关联。

**保留必要的解释空白：**观众理解神迹的情感意义，不必知道每个运作机制。

**让后来人的生活接住故事：**人们怎样命名、纪念、重复这个动作？私人经历怎样成为共同记忆？

**原创示例：**少年提灯等母亲，洪水中撑船救人，最后一趟进入雾中没有回来。此后涨水之夜，河心总出现灯火，引船靠岸。河边人家因此总留最后一盏灯，怕那孩子回来认不得家门。

其中的因果是救人，形象是灯，神异是河心灯火，传承是留灯习俗。四者相互呼应，而非简单添加古风词语。

# 四 普罗普的故事形态学与31个功能项

## 功能是什么

普罗普在1928年的《故事形态学》中主要研究俄罗斯神奇故事。他把人物行动按其对故事进程的作用进行分类，而不是按角色姓名、道具外观或场景分类。

**不同表面行为可承担同一功能：**获赠神马与获得飞毯都可能提供神奇助力。相同行为也可承担不同功能：开头得到钱用来购得助手，与结尾得到奖赏并不是同一个结构作用。

**他的基本主张是：**功能相对稳定、数量有限，省略功能并不改变其余功能的相对次序。这是特定研究中的理论主张，不是所有故事都必须遵守的写作规定。

故事通常有介绍家庭、人物和环境的初始情境，它不计入31项。“加害”与“匮乏”通常放在第8项的两种启动形式中，不因此增加为32项。

## 完整功能表

**01 离家或缺席：**家庭成员离开，或长辈死亡，原有保护产生缺口。例：母亲进山采药。

**02 禁令：**向人物提出告诫或禁止。例：天黑不要应门。

**03 违禁：**禁令被违反。例：孩子打开了门。

**04 侦察：**加害者探听目标信息。例：妖怪打听孩子是否独自在家。

**05 信息泄露：**加害者获得信息。例：邻居说出母亲归来的时间。

**06 欺骗：**加害者设法蒙骗对方。例：妖怪模仿母亲声音。

**07 受骗或无意协助：**受害者中计，帮助骗局推进。例：孩子搬开挡门石。该功能不意味着受害者有罪。

**08 加害或匮乏：**出现伤害或行动需求。例：妹妹被掳走；村庄缺水。

**09 中介或灾难传达：**问题被告知，求助或派遣连接主人公。例：少年得知妹妹失踪。

**10 开始反行动：**主人公同意或决定补救。例：决定去找妹妹。

**11 出发：**主人公离开原处进入主要行动。例：带干粮入山。

**12 赠予者的首次功能或考验：**遇到请求、试探、攻击或较量，为获得助力作准备。例：老人请求分饼。

**13 主人公的反应：**回应考验。例：把最后半块饼分给老人。

**14 获得神奇手段：**得到宝物、能力或助手。例：获得能开石门的笛子。

**15 引导或空间转移：**被带到寻找对象所在之处。例：白鹿驮他越崖。

**16 斗争：**主人公与加害者直接交锋。例：与守洞妖怪搏斗。

**17 标记：**获得后来可供辨识的标记。例：手腕留下月牙伤痕。

**18 胜利：**加害者被击败。例：妖怪被困入石牢。

**19 灾难或匮乏消除：**最初的问题得到补救。例：妹妹获救，泉水恢复。

**20 返回：**踏上归途。例：带妹妹离开妖洞。

**21 追逐：**受到追赶或追害。例：妖怪同伙追来。

**22 获救或摆脱追逐：**逃脱新的危险。例：木梳化为密林阻挡追兵。

**23 未被认出的到达：**到达家乡或别处却未被认出。例：衣衫破烂地进入王城。

**24 冒功或虚假要求：**假主人公提出不实功绩或资格。例：将军声称救了公主。

**25 艰难任务：**提出难以完成的要求。例：打开无人能开启的石匣。

**26 任务完成：**难题解决。例：吹笛使石匣开启。

**27 认出：**真正主人公身份确认。例：公主认出月牙伤痕。

**28 揭露：**假主人公或加害者被揭穿。例：将军无法说明救人经过。

**29 变貌或改观：**获得新的外貌、衣着或显现形象。例：洗去尘土，换上礼服。不能直接等同内心成长。

**30 惩罚：**加害者受惩处。例：冒功者被放逐。

**31 婚礼或登位：**以婚姻、登位或相关奖赏完成最终安置。例：成婚继位。

以上例子为说明功能而自编，不要求全部连成同一条严格情节线。

## 配对关系与使用限制

禁令与违禁、欺骗与受骗、考验与反应、斗争与胜利、追逐与获救、任务与完成、冒功与揭露，构成容易识别的关联。

第18项击败敌人不等于第19项补救完成；第1项家庭成员缺席不等于第11项主人公开始任务。

功能不等于场景，一个功能可以横跨多场戏，一场戏也可能完成多个作用。故事可省略、重复考验，并组合多个行动过程，不能把全篇机械编号一次就算分析完成。

**创作用法：**先写“问题出现 → 决定行动 → 考验 → 获得帮助 → 核心对抗 → 补救”，再判断是否需要归途追害、冒功、识别等后续结构。

# 五 类型电影的常见叙事路径

本章覆盖此前讨论的主要类型与分支。以下是创作性归纳，不是穷尽式分类；例片展示某种路径，不表示作品只能归入这一类。

## 01 爱情

**相遇重聚：**相遇 → 吸引 → 差异显现 → 破裂 → 重新选择。《当哈利遇到莎莉》（1989）。

**外部阻隔：**相爱 → 家庭阶层或时代阻挠 → 争取结合 → 牺牲或分离。《罗密欧与朱丽叶》（1968）。

**限时邂逅：**相遇 → 交流加深 → 亲密 → 时间耗尽 → 余韵。《爱在黎明破晓前》（1995）。

**错过压抑：**吸引 → 试探 → 自我约束或时机错位 → 无法实现 → 回忆。《花样年华》（2000）。

**关系解体：**相爱 → 矛盾累积 → 瓦解 → 回看过去 → 重估爱情。《蓝色情人节》（2010）。

## 02 喜剧

**身份伪装：**不得不伪装 → 获利 → 谎言扩大 → 暴露风险 → 揭穿重组。《热情似火》（1959）。

**陌生环境：**进入异质世界 → 误读规则 → 碰撞 → 暴露荒谬。《憨豆先生的大灾难》（1997）。

**连锁灾难：**简单目标 → 小障碍 → 错误补救 → 更大灾难 → 解决或失败。《飞机 火车和汽车》（1987）。

**错配搭档：**互相嫌弃 → 被迫合作 → 冲突 → 看见价值 → 建立关系。《午夜狂奔》（1988）。

**黑色讽刺：**荒谬规则被认真执行 → 局部合理 → 整体失控 → 灾难结果。《奇爱博士》（1964）。

**重复变奏：**同一处境重来 → 不同尝试 → 失败积累 → 人物改变。《土拨鼠之日》（1993）。

## 03 动作

**孤身围困：**空间被控制 → 孤立 → 逐个破局 → 资源耗尽 → 决战。《虎胆龙威》（1988）。

**营救：**人物遇险 → 追查 → 突破防线 → 救出 → 脱身。《飓风营救》（2008）。

**护送追逐：**送达目标 → 追兵 → 路线受阻 → 代价增长 → 抵达或反攻。《疯狂的麦克斯 狂暴之路》（2015）。

**复仇：**受伤害 → 锁定仇敌 → 连续清算 → 核心对手 → 代价。《杀死比尔》（2003—2004）。

**限时排险：**危机启动 → 明确限制 → 解法失效 → 极限行动。《生死时速》（1994）。

## 04 冒险

**寻宝：**线索 → 解谜赶路 → 竞争者 → 取得目标 → 应对危险。《夺宝奇兵》（1981）。

**远征：**使命 → 未知区域 → 连续试炼 → 损失 → 完成任务。《指环王》三部曲（2001—2003）。

**异界归返：**离家 → 认识异界规则 → 伙伴 → 危机 → 返回。《绿野仙踪》（1939）。

## 05 悬疑与侦探

**谁是凶手：**案件 → 嫌疑人 → 线索与误导 → 重组 → 揭晓。《东方快车谋杀案》（1974）。

**小案大秘密：**普通委托 → 异常 → 权力网络 → 私人秘密 → 真相与正义分离。《唐人街》（1974）。

**追凶执念：**调查 → 线索断裂 → 时间流逝 → 生活被侵蚀 → 有限答案。《十二宫》（2007）。

**认知翻转：**可信解释 → 不一致 → 追查 → 基础认识推翻 → 重解前文。《禁闭岛》（2010）。

**矛盾证词：**同一事件 → 多人讲述 → 冲突 → 事实不稳定 → 人性追问。《罗生门》（1950）。

## 06 惊悚

**无辜卷入：**误认或偶然 → 追捕 → 求助失败 → 边逃边查 → 对抗。《西北偏北》（1959）。

**猫鼠博弈：**建立对抗 → 试探 → 攻守转换 → 逼近弱点 → 摊牌。《沉默的羔羊》（1991）。

**关系囚禁：**建立依赖 → 发现控制 → 逃离失败 → 秘密反抗 → 决战。《危情十日》（1990）。

**阴谋监视：**异常 → 深查 → 被监视 → 渠道失效 → 揭露或被吞没。《窃听大阴谋》（1974）。

## 07 恐怖

**怪物猎杀：**异常 → 威胁确认 → 人员减少 → 发现规则 → 求生。《异形》（1979）。

**附身驱魔：**异常 → 普通解释失败 → 确认问题 → 仪式对抗 → 代价。《驱魔人》（1973）。

**诅咒调查：**接触禁物 → 期限 → 溯源 → 尝试解除 → 规则缺口。《午夜凶铃》（1998）。

**跟踪杀戮：**威胁潜伏 → 人物未察觉 → 袭击 → 识别危险 → 反击。《月光光心慌慌》（1978）。

**身体异变：**变化启动 → 短期获益 → 失控 → 人格关系崩解 → 不可逆结果。《变蝇人》（1986）。

**仪式陷阱：**外来者进入 → 异常 → 调查抵抗 → 发现早被安排。《异教徒》（1973）。

## 08 犯罪与黑帮

**崛起衰落：**边缘 → 入伙 → 权力财富 → 猜忌自负 → 瓦解。《好家伙》（1990）。

**家族继承：**拒绝家业 → 家庭受威胁 → 介入 → 掌权 → 道德改变。《教父》（1972）。

**双重身份：**潜入 → 建立关系 → 忠诚冲突 → 暴露危机 → 清算。《无间道》（2002）。

**退出失败：**重新生活 → 旧关系追索 → 妥协 → 再陷其中 → 无法脱身。《情枭的黎明》（1993）。

## 09 劫盗与骗局

**计划执行：**目标 → 组队 → 准备 → 执行 → 临场应变 → 撤离。《十一罗汉》（2001）。

**计划失控：**精密准备 → 行动 → 意外 → 利益冲突 → 崩溃。《杀手》（1956）。

**隐藏计划：**部分方案 → 失败表象 → 对手放松 → 另一层行动揭晓。《骗中骗》（1973）。

**事后重建：**行动失败 → 幸存者聚集 → 怀疑 → 回溯 → 内奸或误判。《落水狗》（1992）。

## 10 警匪与程序调查

**职业调查：**案件 → 勘查询问 → 假设 → 验证失败 → 调整 → 结果。《杀人回忆》（2003）。

**警匪镜像：**双方准备 → 互相识别 → 追捕 → 私生活受损 → 交锋。《盗火线》（1995）。

**内部腐败：**发现违规 → 拒绝同流 → 被孤立 → 举报 → 代价。《冲突》（1973，Serpico）。

## 11 法庭与法律

**辩护翻案：**不利案件 → 调查 → 证据受阻 → 交锋 → 突破 → 裁决。《义海雄风》（1992）。

**封闭论证：**共识 → 少数质疑 → 重审证据 → 偏见暴露 → 判断改变。《十二怒汉》（1957）。

**法律与正义分离：**不公 → 证明 → 偏见 → 程序结果 → 道德余波。《杀死一只知更鸟》（1962）。

**制度审判：**被告受审 → 行为追问 → 制度辩护 → 责任扩大。《纽伦堡的审判》（1961）。

## 12 科幻

**接触未知：**异常来临 → 交流 → 误解 → 理解方式变化 → 文明选择。《降临》（2016）。

**技术反噬：**创造 → 获益 → 失控 → 承担后果 → 重定边界。《侏罗纪公园》（1993）。

**虚假世界觉醒：**日常裂缝 → 真相 → 接受 → 学习规则 → 反抗。《黑客帝国》（1999）。

**改写时间：**穿越 → 改变事件 → 连锁后果 → 修补 → 返回。《回到未来》（1985）。

**时间循环：**重复 → 积累信息 → 试错 → 寻找条件 → 突破。《明日边缘》（2014）。

**人类边界：**分类任务 → 接触异类 → 标准动摇 → 身份伦理危机 → 选择。《银翼杀手》（1982）。

**宇宙探索：**远征 → 不可理解之物 → 解释失效 → 新存在尺度。《2001太空漫游》（1968）。

## 13 奇幻与神话童话

**异界试炼：**误入 → 失去保护 → 学规则 → 建关系 → 试炼 → 回归。《千与千寻》（2001）。

**命运使命：**特殊身份 → 抗拒责任 → 试炼 → 代价 → 承担。《狮子王》（1994）。

**愿望代价：**愿望 → 实现 → 满足 → 代价 → 重选。《大》（1988）。

**诅咒解除：**诅咒 → 相遇 → 关系变化 → 考验 → 解除或接受。《美女与野兽》（1991）。

**现实神话双线：**现实压迫 → 神话任务 → 相互映照 → 关键选择 → 含混或超越结尾。《潘神的迷宫》（2006）。

## 14 超级英雄电影

**起源责任：**普通身份 → 能力 → 误用逃避 → 代价 → 接受责任 → 胜利。《蜘蛛侠》（2002）。

**信念受审：**守护秩序 → 敌人攻击原则 → 手段失败 → 艰难选择 → 后果。《蝙蝠侠 黑暗骑士》（2008）。

**团队形成：**各自行动 → 召集 → 内部冲突 → 共同危机 → 协作。《复仇者联盟》（2012）。

**衰老传承：**力量衰退 → 新保护对象 → 再行动 → 最后付出 → 传承。《金刚狼3 殊死一战》（2017）。

## 15 战争

**小队任务：**接令 → 敌境 → 减员 → 质疑 → 最终行动。《拯救大兵瑞恩》（1998）。

**新兵失去天真：**期待 → 训练 → 战场 → 失序 → 信念破裂。《野战排》（1986）。

**战役群像：**部署 → 局部冲突 → 战况变化 → 汇合 → 胜负代价。《最长的一天》（1962）。

**深入腹地：**任务 → 逐站深入 → 常识失效 → 极端人物 → 精神危机。《现代启示录》（1979）。

**平民求生：**战争侵入 → 家园毁坏 → 逃避忍受 → 损失 → 幸存或毁灭。《自己去看》（1985）。

## 16 西部

**陌生人护卫：**到达 → 发现压迫 → 介入 → 击退威胁 → 离去。《原野奇侠》（1953）。

**孤立守城：**威胁逼近 → 求援 → 众人退出 → 独自准备 → 对抗。《正午》（1952）。

**长途追寻：**家园受袭 → 追踪 → 岁月流逝 → 执念变形 → 选择。《搜索者》（1956）。

**暴力清算：**退隐 → 被召回 → 传奇拆解 → 暴力回归 → 道德代价。《不可饶恕》（1992）。

## 17 武侠与功夫

**学艺雪耻：**受压迫 → 拜师 → 训练 → 领悟 → 战胜强敌。《少林三十六房》（1978）。

**伤残重建：**重伤 → 失去身份 → 新方法 → 重返冲突 → 重新定位。《独臂刀》（1967）。

**护送围局：**追杀 → 多方聚集 → 身份试探 → 结盟伏击 → 突围。《龙门客栈》（1967）。

**情义自由：**事件牵连 → 欲望礼法冲突 → 关系破裂 → 决战失去。《卧虎藏龙》（2000）。

**刺杀转向：**接近目标 → 讲述前因 → 动机显露 → 重估 → 是否出手。《英雄》（2002）。

## 18 灾难与求生

**预警被忽视：**异常 → 警告受阻 → 灾难 → 求生 → 代价余波。《大白鲨》（1975，兼具怪物与惊悚结构）。

**封闭逃生：**空间破坏 → 出口失效 → 临时领袖 → 逐关突围 → 幸存。《海神号遇险记》（1972）。

**技术救援：**故障 → 资源受限 → 多方协作 → 连续解题 → 返回。《阿波罗13号》（1995）。

**孤独生存：**隔绝 → 生理需求 → 生活秩序 → 精神危机 → 离开或适应。《荒岛余生》（2000）。

## 19 体育与竞技

**弱者挑战：**不被看好 → 机会 → 训练挫折 → 比赛 → 重定成功。《洛奇》（1976）。

**团队重建：**失序 → 新方法 → 抵触 → 信任 → 检验。《火爆教头》（1986，Hoosiers）。

**冠军自毁：**天赋 → 上升 → 缺陷侵蚀关系 → 衰落 → 面对自己。《愤怒的公牛》（1980）。

**改变规则：**劣势 → 新方法 → 体制抵抗 → 验证 → 成绩与制度意义分离。《点球成金》（2011）。

## 20 成长与青春

**一次冒险启蒙：**日常 → 秘密计划 → 离家 → 接触残酷 → 改变。《伴我同行》（1986）。

**家庭分离：**独立欲望 → 冲突 → 尝试身份 → 失落 → 重解家庭。《伯德小姐》（2017）。

**权威冲突：**需求不被承认 → 反抗 → 惩罚升级 → 逃离 → 开放未来。《四百击》（1959）。

**时间累积：**生活片段 → 环境关系变化 → 选择形成 → 新阶段。《少年时代》（2014）。

## 21 家庭婚姻与情节剧

**秩序重建：**成员离开 → 角色重分配 → 学习照料 → 新冲突 → 重建。《克莱默夫妇》（1979）。

**代际失去：**探访 → 期待落空 → 失望累积 → 死亡离别 → 迟来理解。《东京物语》（1953）。

**婚姻解体：**失衡 → 分居 → 协商 → 伤害扩大 → 告别或新关系。《婚姻故事》（2019）。

## 22 公路

## 23 历史传记与史诗

**一生起落：**出身 → 机会 → 地位 → 挫折 → 晚年。《末代皇帝》（1987）。

**关键时期：**聚焦任务 → 阻力 → 私人代价 → 选择 → 历史结果。《林肯》（2012）。

**英雄与历史：**抱负 → 历史舞台 → 成就 → 身份撕裂 → 后果。《阿拉伯的劳伦斯》（1962）。

**家庭承受时代：**家庭 → 社会变动 → 损失 → 重建 → 时间延续。《活着》（1994）。

**竞争者回忆：**旁人回望 → 天才登场 → 羡慕冲突 → 衰败 → 有偏见的评价。《莫扎特传》（1984，戏剧化叙述不等于史实）。

## 24 歌舞与音乐

**后台演出：**筹备 → 人才资金问题 → 关系冲突 → 危机 → 登台。《四十二街》（1933）。

**爱情与歌舞：**相遇 → 表达欲望 → 事业关系受阻 → 合作 → 情感结果。《雨中曲》（1952）。

**成名消耗：**发现才华 → 成名 → 地位不等 → 关系受损 → 失去重建。《一个明星的诞生》（1954）。

**表演评论现实：**现实冲突 → 舞台幻想介入 → 讽刺揭示 → 现实结局。《歌厅》（1972）。

## 25 社会问题与现实主义剧情

**小目标受阻：**生活需求 → 障碍 → 求助 → 社会限制 → 道德困境。《偷自行车的人》（1948）。

**个人维权：**不公 → 寻找程序 → 碰壁 → 升级 → 结果产生新矛盾。《秋菊打官司》（1992）。

**制度网络：**多人行动 → 利益相连 → 相互影响 → 整体困境。《毒品网络》（2000）。

## 其他标签的使用

动画可承载冒险伙伴关系，如《玩具总动员》，也可承载战争家庭悲剧，如《萤火虫之墓》。儿童与合家欢首先约束受众及表达尺度。

黑色电影涉及历史传统、风格和世界观。《双重赔偿》可概括为欲望诱惑 → 犯罪 → 互疑 → 毁灭。

艺术电影可以采用弱目标、游移、重复或记忆的不稳定；不能简单认定其没有结构。

纪录片可采用观察、调查、论证、人物历程、日记或档案重组。它与现实材料和真实性的关系，不应由虚构剧情模板取代。

# 六 救猫咪的十种故事类型

布莱克 斯奈德的分类着眼于故事运转机制，与市场类型不是同一层面。以下保留英文以便查阅。三要素属于该体系；箭头路径与变化提示是实用归纳。十种类型也不等同该体系另行提出的15节拍表。

## 01 屋里有怪物 Monster in the House

**要素：**怪物、受限空间、引入灾祸的过失或越界。

**路径：**生活秩序 → 越界引祸 → 困在威胁范围 → 常规手段失败 → 伤亡升级 → 理解规则弱点 → 反击逃脱或覆灭。

**变化：**外部入侵《异形》；利益纵容危险《大白鲨》；亲密关系威胁《致命诱惑》。

**检查：**为什么无法离开？谁的决定让威胁进入？过失不必来自受害者，不应被理解为受害者有罪。

## 02 寻找金羊毛 Golden Fleece

**要素：**旅程、团队、目标或奖赏。

**路径：**确定目标 → 结伴出发 → 连续考验 → 团队矛盾 → 计划或信念失效 → 重解真正需要 → 以新方式面对终点。

**变化：**寻找归途《绿野仙踪》；家庭公路《阳光小美女》；竞技征程《洛奇》。

**检查：**每站改变了谁？外部奖赏与真实收获是否不同？旅程可以是地理移动，也可以是一系列成长阶段。

## 03 瓶中精灵 Out of the Bottle

**要素：**愿望、神奇干预、教训。

**路径：**不满或愿望 → 异常改变生活 → 利用好处 → 代价显现 → 欲望失效 → 新选择 → 解除异常或获得新意义。

**变化：**愿望成真《大》；能力负担《冒牌天神》；异常循环《土拨鼠之日》。

**检查：**神奇机制是否针对人物盲点？不一定由主人公亲口许愿，也可以是被迫面对异常处境。

## 04 普通人陷入困境 Dude with a Problem

**要素：**无端卷入的主人公、突发事件、生死危机。

**路径：**日常 → 突发危机 → 求助失效 → 自行应对 → 危险升级资源减少 → 极限选择 → 幸存获救或牺牲。

**变化：**偶然卷入《虎胆龙威》；灾难求生《泰坦尼克号》；技术危机《阿波罗13号》。

**检查：**时间、氧气、伤势、燃料等限制是否具体？“普通”不意味着没有专业能力，而是面对超出日常预期的处境。

## 05 人生转折 Rites of Passage

**要素：**人生难题、错误应对、接受。

**路径：**难以逆转的变化 → 拒绝承认 → 控制逃避或自伤 → 恶化 → 旧办法失败 → 接受现实局限 → 新生活方式。

**变化：**创伤丧失《普通人》；成瘾康复《28天》；中年危机《十全十美》。

**检查：**人物终于愿意面对什么？接受不是顺从不公，而是停止无效应对，把行动转向仍可改变的部分。

## 06 伙伴之情 Buddy Love

**要素：**情感上有所欠缺的主人公、互补对象、关系阻碍。

**路径：**有局限的生活 → 遇见对方 → 抵触或被迫同行 → 依赖受益 → 关系破裂 → 分离显出价值 → 主动改变并重建或告别。

**变化：**爱情《当哈利遇到莎莉》；从利用到关爱《雨人》；跨物种友谊《E.T.外星人》。

**检查：**为什么偏偏是这个伙伴能改变他？情感欠缺是具体信任或关爱能力的问题，不意味着单身本身不完整。

## 07 追查缘由 Whydunit

**要素：**调查者、秘密、黑暗转折。

**路径：**谜团 → 追踪 → 表面解释失败 → 深层关系 → 调查者受威胁诱惑或越界 → 真相 → 重解人性与世界。

**变化：**权力欲望《唐人街》；人生秘密《公民凯恩》；公共调查《总统班底》。

**检查：**揭晓除了提供名字，还改变什么理解？显著变化也可能主要发生在观众认识中。

## 08 愚者成功 Fool Triumphant

**要素：**被低估的愚者、强势既有秩序、身份地位转变。

**路径：**轻视 → 进入权威环境 → 按独特方式行动 → 意外成果 → 排斥或利用 → 重大考验 → 独特性显出价值。

**变化：**天真者穿越社会《阿甘正传》；反抗刻板印象《律政俏佳人》；权力误读《富贵逼人来》。

**检查：**曾被嘲笑的特点是否参与最终结果？愚者是外界判断，并不必然真的缺乏能力；故事也可以是讽刺。

## 09 制度化 Institutionalized

**要素：**群体、选择、牺牲。

**路径：**进入或重面对群体 → 规则与归属 → 获益 → 看见代价 → 个体价值冲突 → 选择 → 融入反抗或离开。

**变化：**被吸收《教父》；抵抗逃离《肖申克的救赎》；反抗牺牲《飞越疯人院》。

**检查：**群体为什么值得留恋？离开要失去什么？组织可以是家庭、军队、学校、公司、监狱或帮派。

## 10 超级英雄 Superhero

**要素：**非凡力量、强敌、特殊身份的负担。

**路径：**特殊性显现 → 与日常产生裂缝 → 能力带来责任代价 → 强敌挑战 → 动摇逃避 → 接受负担 → 完成选择与对抗。

**变化：**起源责任《蜘蛛侠》；被放逐的卓越者《角斗士》；才能与个人困境《美丽心灵》。

**检查：**非凡能力使人物能做什么，又失去什么？这一类别比漫画英雄更宽；负担是叙事概念，不能推论才能必然伴随疾病。

## 容易混淆的类型

**怪物入屋与普通人困境：**前者强调威胁、困局和越界；后者强调突发危机中的应变。可交叉，但不能见到危险就认定同类。

**金羊毛与伙伴之情：**前者以旅程试炼组织故事；后者以关系变化组织高潮。判断删去哪条线会让故事失去核心。

**人生转折与超级英雄：**前者主要处理必须接受的人生现实；后者主要处理特殊能力与责任的代价。

**愚者成功与制度化：**前者突出被低估者对秩序的反照；后者突出个人对归属和自由的选择。

# 七 跨类型的叙述方式

叙述方式决定观众怎样知道故事，不必改变人物实际经历的时间顺序。下列项目分别涉及时间、视角、篇章或信息组织，可以叠加。

**01 单线顺叙：**沿主要因果链向前。《洛奇》。适合清晰累积目标与代价。

**02 结果先行：**先呈现结局或危机，再追溯原因。《日落大道》。悬念由“会怎样”转为“为何如此”。

**03 逆向叙述：**越往后看，越接近早先原因。《记忆碎片》的逆向彩色段落与正向黑白段落交织。

**04 双线平行：**两条行动对照或交汇。《盗火线》。需明确两线如何互相改变意义。

**05 多线交织：**多人或多地形成事件网络。《纳什维尔》。需要主题、事件或空间的连接原则。

**06 多视角重述：**同一事件由不同人物讲述。《罗生门》。差异要改变判断，而非只重复信息。

**07 回忆框架：**当下讲述包裹过去。《泰坦尼克号》。检查当下框架是否增加意义。

**08 非线性拼图：**打乱片段顺序，逐渐建立关系。《低俗小说》。信息重排需要有观看收益。

**09 重复与分岔：**相似起点多次展开。《罗拉快跑》。比较选择、偶然与结果。

**10 段落串联：**相遇、任务或生活片段形成整体。《逍遥骑士》。依靠累积、对照和情绪递进保持方向。

**11 不同时间尺度交织：**不同长度的行动在叙述中汇合。《敦刻尔克》的陆海空时间线。

**12 近实时：**银幕时间接近事件时间。《正午》。持续压力来自时间消耗。

**13 故事集与松散框架：**多个内部故事由题旨、人物或段落连接。《十日谈》（1971）。不必强求所有段落都有同一个外层讲述者。

**14 不可靠叙述：**叙述者的记忆、偏见或欺骗影响呈现。《非常嫌疑犯》（1995）。应区分角色说谎与影片公平提供的识别线索。

## 信息差的三种基本选择

**观众与人物同时知道：**共同调查与发现，适合谜题式悬疑。

**观众先知道：**看人物走向危险，形成悬念；恐怖与惊悚常用。

**人物先知道而观众后知：**形成惊奇或重释；需防止为了反转而无依据地遮蔽关键信息。

开放结尾不等于没有结尾。可以完成行动或情感变化，同时保留事实解释或未来走向。

# 八 综合创作流程与示范

## 从想法到大纲的八步

**第一步 确定主要观看期待：**观众最关心相爱、真相、求生、成功还是归属？选择主要市场类型。

**第二步 确定核心行动：**寻找、保护、逃离、证明、修复或复仇。把抽象主题转成可行动的目标。

**第三步 选择主要故事机制：**用救猫咪十类检查高潮最需要回答什么问题，必要时加入一条辅助关系线。

**第四步 写人物变化：**起初相信什么？哪些行动使其信念受到检验？结尾接受、拒绝或失去了什么？

**第五步 写三幕骨架：**为什么开始 → 为什么越来越难 → 最后做什么导致结果。

**第六步 用起承转合复核：**开头提出什么 → 中段怎样发展 → 哪里真正改变 → 结尾回应什么。

**第七步 标识重要功能：**禁令、考验、助力、补救、识别等是否有铺垫和兑现？无需凑齐31项。

**第八步 选择叙述方式与质感：**信息何时给、从谁看、是否需要倒叙；若追求传说感，增加有意义的遗存和传承。

## 原创示范 守灯的少年

**故事前提：**河湾洪水将至，一个害怕黑水的少年，要把困在旧渡口的母亲带回村子。

**类型与路径：**灾难求生为主，家庭关系为辅；由突发洪水发动，采用救猫咪的普通人陷入困境框架。若将重点改为寻求神灯的长途试炼，则会转向金羊毛，不能只改标签。

**第一幕：**少年平时只敢站岸边举灯。洪水切断渡口，母亲失联；他发现熟悉水路的大人也无法及时赶到，决定撑小船出发。

**第二幕：**船行受阻，灯油减少；他发现沿途还有孩子和老人。只找母亲的计划与救其他人的责任冲突。他数次往返，学会辨认水流，却失去安全返航的时间窗口。

**第三幕：**他把最后的位置留给被困者，让母亲带他们离开，自己举灯引路。灯火随后消失在雾里。结尾转到多年以后：村民在涨水夜保留一盏灯。

**起承转合：**起是怕水却等母亲；承是举灯入水救援；转是从“把母亲带回”转为“让更多人回家”；合是后来人也为他留灯。

**功能参考：**匮乏与危机 → 灾难传达 → 决定反行动 → 出发 → 获得援助 → 引导 → 补救。并非严格验证普罗普原模型，只是借用功能词检查行动。

**叙述选择：**可从今天留灯习俗开始，再讲往事；也可顺叙到结尾才揭示习俗。前者制造来历悬念，后者强调情感延续。

**传说感：**灯从等待母亲的物件，变成救人的工具，再成为河心异象与地方习俗。神异必须由此前行动获得意义。

此结尾采用牺牲版本，也可改为少年幸存。是否牺牲由作品的年龄定位、主题及整体情感决定，不能把死亡视为传说感的必要条件。

# 九 检查清单与参考资料

## 改稿检查

目标是否明确，风险是否具体，人物是否有行动机会？

中段每次挫折是否改变资源、关系、认识或选择，而非重复原地受阻？

转折是否来自已有因果、人物选择或充分铺垫，而非随机救场？

高潮是否回应主要类型承诺，同时体现人物的价值选择？

胜利是否真正消除最初问题，还是只击败一个对手？

线索是否能承受第二次观看，神奇规则是否前后一致？

多线、倒叙和框架是否带来意义，还是增加理解负担？

结尾是否既交代结果，又回应开头？未解释部分是有意留白还是漏写？

文化质感是否来自生活细节、人伦、地方与礼俗，而非只有服装和古风语言？
