# 《北京一家人》项目理解与创作依据

学习日期：2026-11-17。本文是对现有资料的工作理解，不是新增或已获批准的设定。未对资料中的外部事实、引语、案例出处进行独立核验。

## 2. 项目定位

计划 520 集，每集 10 分钟，面向 5—10 岁儿童，并兼顾亲子观看。类型为有奇幻色彩的都市家庭情景轻喜剧，核心是温暖现实主义。采用固定人物关系、单集独立完整的串珠式结构。

舞台是当代北京什刹海胡同的新中式带露台四合院，三代同堂。先扎根家庭、胡同、学校，再按需要扩展北京其他场景。传统文化需要体现当代生活中的意义，北京文化需要参与人物行动与情节因果。

七大主题：爱、品德、成才、健康、生命、劳动、环保。单集集中表达一个核心价值，通过选择、行动和后果让观众领悟。

## 3. 双男主与人物关系

- 康小宁：9 岁、小学三年级。好奇、善良、勇敢，好胜、会走神，有小缺点但能承担责任。剧作上的男一号，需求与困惑是故事主要动力。
- 招财童子／小康娃：视觉年龄 3 岁，心智年龄 8 岁，真实年龄数千岁。傲娇自信、嘴硬心软、爱吃、爱谈条件，古老知识与现代生活认知存在落差。是核心商业 IP，也是有意愿、有判断的伙伴，不能只承担递道具的功能。
- 二人互补，也会目标一致而方法不同；彼此都可能判断错误、互相帮助。不能固定成一人永远闯祸、另一人永远正确。
- 康小美：12 岁、初一，学霸、好胜、外冷内热，嘴上嫌弃却保护弟弟，也有自己的压力。
- 康乐：38 岁，自由职业潮流玩具设计师。幽默、包容、情绪稳定，承担很多家务，有时过于佛系。
- 乔妍：38 岁，智能机器人科技公司市场总监。高效、有责任感，不怒自威；不能简单写成唠叨或蛮横的妈妈。
- 康承基：69 岁，退休高中历史老师。传统文化知识丰富，好为人师，有清北执念；嘴馋，与小康娃可形成偷吃同盟。
- 安好：65 岁，退休京剧演员。时尚、热心、厨艺好、温柔包容，是家庭情感支撑。
- 豆包：中华田园大橘猫，兼有陪伴、动作喜剧和调和气氛的作用。
- 张菲儿：8 岁的新同学，中美混血小海归，喜欢科技和中国文化。
- 南国华／南瓜：8 岁，外向好动，康小宁的同学、好友与竞争伙伴。

配角按情节需要登场，不要求每集全家到齐。家庭成员在一组剧集中均衡展开。

## 4. 世界与奇幻边界

主大纲中的来历是招财童子贪玩乱施法，经镜面折射击中自身被封印，后被康小宁解封。金锁可变幻道具，金手镯是钥匙；法术有次数或时间限制，发髻可表现施法状态；能够与动物交流。

弱化仙界，不发展师父、妖怪、龙女轮番下凡的支线。家人可以对小康娃的身份各有理解，身份的解释保持克制。避免让法术取代劳动、学习、关系修复和人物选择。

会议提出障眼法、实体搬运、借助物体飞行、限时穿越与沙漏等办法，但穿越时长明确尚未统一。早期分析表中的“法宝不能重复使用”没有被主大纲明确确认为通用规则。写单集前应说清该集能力、触发、限制、失效和恢复条件，不能临近结尾突然增加能力救场。

年龄与基本生活状态保持稳定，尽量回避过年、生日带来的连续计龄。大纲提出单集成长、新集归零；会议同时要求学过京剧等具体经历保持连贯。暂按“人物基本状态稳定，已建立事实不随意推翻”理解，长期连续性仍需明确。

## 5. 故事与喜剧尺度

1. 从儿童真实需求、生活事件或困惑出发；开场有吸引力，信息不必按发生顺序全部交代。
2. 冲突来自观念差异、误解、目标阻碍、能力限制或人物盲点。家庭底色是关爱与包容。
3. 笑点来自性格、动作、信息差、错误理解和递进变化。不要主要依赖老人受苦、全家狼狈、羞辱或幸灾乐祸。
4. 双男主都要实际改变剧情，小康娃可以帮忙、帮倒忙、提出不同意见或受到启发。
5. 关键转折有铺垫；人物的最终行动导致结果，不能只说“下次不这样了”。
6. 允许没拿冠军但收获合作、勇气与努力的结尾。善意不等于轻易成功。
7. 可以使用面向观众的吐槽、第四面墙和幻想／回忆中的漫画化表现，但需服务节奏。
8. 写可见可听的动作与变化；文化、科普、作业年级和专业细节要适配实际情境。
9. 北京对白以普通话为主，适量使用角色化地域表达；文化不只靠豆汁、胡同和地标名称装饰。
10. 会议明确提醒尊重隐私、避免把劳动写成惩罚，也不宜凭空给现实地区贴负面标签。

## 6. 写作流程与交付参考

选题与素材 → 同题多个故事方向 → 梗概筛选深化 → 分场大纲 → 剧本初稿 → 人工审改 → 样本与故事元素入库。

会议补充要求：单集标题五个字；梗概约 500—1000 字；分场约 1500—2000 字；正文约 4000—5000 字，对白宜约 1200—1300 字。对白量和正文总量应分开核算，最终仍需检查实际时长。

动作与对白分行，对白加粗，避免对白重复解释正在发生的动作。分场先审清目标、因果、笑点和反转，再展开对白。

故事性、价值观、文化性、喜剧性、逻辑性是五个验收维度；另检查儿童视角、人物一致性与可视化表达。

三幕式、起承转合、救猫咪十类、普罗普功能和叙述方式各有用途，应按故事选择，不机械套用成人电影中的极端反派、死亡危机或“一无所有”。
