# 剧本系统 · 编剧工作包

[打开剧本系统 · 在线使用页](https://ziyetsui.github.io/script-system/)

从一个生活点子写到约 500 字的单集大纲，或带着已有稿件，请一个岗位解决眼前最难写的一场。示例取自《北京一家人》的家庭轻喜剧创作。

每项用法分列中文名称和英文名称。英文栏给出便于阅读的译名，等宽字标出已有的英文声明名或目录名。复制提示词中的仓内路径即可调用。

**第一次使用**，打开编剧指南，下载仓库、选好工作目录，复制第一句试写。Codex、Claude Code 和 Cursor 都可以按文件路径读同一份材料。[从 setup 开始](docs/github-guide/README.md)

**正在写一集**，按手上的稿件直接跳到对应阶段。GitHub 上可以直接读 Markdown 或 PDF。HTML 随仓库下载后在浏览器打开，可离线搜索和按章查阅。[编剧实战路线图](docs/github-guide/roadmap.md) · [PDF 手册](docs/github-guide/roadmap.pdf) · [离线 HTML](docs/github-guide/roadmap.html)

## 按任务查用法

从上面三项高频示例开始，或点下表跳到手上的任务。打开同时包含 `skills/`、`agents/`、`automations/` 的仓库根目录，在 Codex、Claude Code 或 Cursor 的对话中复制一项的**第一句**。收到答复后，按“判断”选定要保留的动作，再单独复制**第二句**。输入里提到的上版稿、热点卡、原作片段要一同贴上。

同名的岗位和技能分开列。例如独立卡在一场戏时用“找梗”技能，整集协作时将带编号的候选交给“找梗”岗位。`群策` 和 `swarm` 共用分派规则。首轮产物栏写的是该提示要求交回的东西；标有“历史答卷”的链接可以检查当时实际交到哪里。第二句供编剧按当前答复调整。

## 五个编剧岗位

| 中文名称 | 英文名称 | 命令或用法 | 可复制提示词 |
| --- | --- | --- | --- |
| [故事新编](agents/故事新编.md)<br>教学示例 | Story Reteller<br>`story-reteller` | **什么时候用**　有教育题或典故，需要把两难换成北京孩子自己的选择。<br>**先给**　给同一热点卡、相关总纲价值、人物限制和能核原文的典故；题材已在对话里可沿用。<br>**首轮产物**　一张注明出处的候选卡，把原人物的选择、康家原创事件、冲突代价和待试的一场分开。<br>**判断**　遮住典故名字，看看孩子还能不能自己行动。若只剩长辈讲寓意，请补孩子要付的代价。 | **第一句**　请读 agents/故事新编.md。沿用刚选的热点卡，从《曾子杀猪》取“大人随口答应、孩子当真”。写一张康家候选卡，给原典依据、孩子今天会损失什么、哪个动作逼大人回应。<br><br>**第二句**　把承诺兑现的决定留给爸爸，让小宁先为这句承诺付出一点实在的东西。改这一笔，交给剧本模型比较。 |
| [爆款复刻](agents/爆款复刻.md)<br>教学示例 | Reference Adapter<br>`reference-adapter` | **什么时候用**　想借一部成熟剧集的具体机制，已经知道本集卡在什么地方。<br>**先给**　给选定热点、想保住的动作、可检索的作品或集；有逐字稿或原片位置就一起给。<br>**首轮产物**　原剧可定位的动作与后果、可迁移机制，以及用康家人物和新道具写出的原创候选。<br>**判断**　把原台词拿掉，看康家新场景能否靠人物各自的愿望推下去。核对短引、集号或行号。 | **第一句**　请读 agents/爆款复刻.md。沿用所选热点。康家这场里小宁和爸爸分别替爷爷瞒事，请从一部家庭喜剧找能核到的群口露馅场面，定位到集和动作，再换成修车钥匙写一张新候选卡。<br><br>**第二句**　保留两个人各自说得通、合起来露馅的机制。道具只留一把钥匙，把泄底的动作交给爷爷，交给剧本模型。 |
| [剧本模型](agents/剧本模型.md)<br>教学示例 | Story Model<br>`story-model` | **什么时候用**　已有候选，选不定主角、升级方式或高潮。<br>**先给**　给两条取材路线所得的候选或缺口、热点依据、总纲限制和已定结局。<br>**首轮产物**　两到三个行动与代价不同的候选，指出每案还需向找梗岗位追问的具体卡点。<br>**判断**　把高潮分别讲给没读稿的人；对方能否说清谁有权选、选择为什么难、前一场怎样逼到这里？ | **第一句**　请读 agents/剧本模型.md。沿用两张候选卡：小宁替爷爷接下修车活，爷爷想歇一天。比较“小宁主动撤单”和“爷爷第一次当面拒绝”两个高潮，写明跟谁看、谁吃亏，先停在选型。<br><br>**第二句**　我选小宁撤单。保留他一开始真心帮忙，只把第一次补救引出第二辆车的那一步交给找梗。 |
| [找梗](agents/找梗.md)<br>教学示例 | Trope Finder<br>`trope-finder` | **什么时候用**　候选已定，要把一场具体的断点交给专人找接法。<br>**先给**　从剧本模型接候选编号、前后场、禁用项和保留动作；允许读相关梗库。<br>**首轮产物**　带候选编号的“动作 → 后果 → 下一步选择”，附原剧或技法来源、适用前提和材料缺口，回给招财童子。<br>**判断**　逐条问下一步是谁非做不可。把原剧的可核桥段和这集的新事件分别读一遍。 | **第一句**　请读 agents/找梗.md。请把 A 案交给找梗岗位。前场小宁替爷爷发修车号码，后场他得亲自撤单。中间只许用院门、车铃和一把锁。查两种让规矩反而添乱的机制，给出处。<br><br>**第二句**　采用街坊锁车离开那条。只展开钥匙交错的三个节拍，把最后的撤单权留给小宁，回交主稿。 |
| [导演审稿](agents/导演审稿.md)<br>教学示例 | Outline Director<br>`outline-director` | **什么时候用**　已有完整大纲和难写的关键戏，准备决定是否返工。<br>**先给**　给稿号、选题与总纲依据、大纲全文、关键戏、已认可段落。<br>**首轮产物**　五项有稿内依据的意见，附问题桥段、返工去向和复核办法；改完可再交该岗位复读。<br>**判断**　看意见能否指到哪场哪一下。如果“缺北京特色”只得到换地名，让它指出哪条公共生活规则会改变人物行动。 | **第一句**　请读 agents/导演审稿.md。请按导演审稿岗位复核上文 V2 和门口那场试写。保住奶奶赴约。按五项标准各指一处稿内动作，指出抽掉这项社会议题后哪次选择会消失，列最先该返工的一处。<br><br>**第二句**　只退回中段给剧本模型。保留开头和结尾，拿到 V3 后复核小宁的那次选择，等我决定是否认可。 |

## 找梗与多方案比较

| 中文名称 | 英文名称 | 命令或用法 | 可复制提示词 |
| --- | --- | --- | --- |
| [找梗](skills/找梗/SKILL.md)<br>教学示例 | Trope Search | **什么时候用**　中段人物反复说同一句话，下一场没人接招。<br>**先给**　给当前人物、他想做的事和卡住的一步；有禁用的解法就一并给。<br>**首轮产物**　两个不同的动作后果，各带能写进下一场的接招；剧库命中附来源，方法示例标原创。<br>**判断**　逐个问：孩子做了什么，谁因此改变本来的打算？两个选项若只换道具，让它再换因果。 | **第一句**　请读 skills/找梗/SKILL.md。小宁想拖住要出门的奶奶，让她看完他排的戏。前两次都只会说“再等一分钟”。给两种下一拍，奶奶最终能赴约，别用电话救场。<br><br>**第二句**　我选让小宁自己把节目压短的走法。写到爷爷划掉他苦练的转身，他第一次喊停。保留奶奶出门。 |
| [群策](skills/群策/SKILL.md)<br>教学示例 | Writers’ Room Brainstorm | **什么时候用**　还没定下要写哪种高潮，想把同一难题交给几个创作方向比较。<br>**先给**　贴当前稿，或沿用同一会话；指出眼下要定的事和一个必留条件。<br>**首轮产物**　几种可比较的试写，说明每条能保住什么、会失去什么，并列出实际尝试的方向。<br>**判断**　把三种走法的最后一个动词圈出来。优先保留孩子亲自下决定、又舍不得付代价的一版。 | **第一句**　请读 skills/群策/SKILL.md。小宁给奶奶搭台，她已经约了朋友。高潮可以发生在台上，也可以发生在门口。给三种行动和代价都不同的走法，让我选。<br><br>**第二句**　我选门口那版。只写从奶奶拿包到小宁收回节目单的半页，留下他还想演的一个动作。 |
| [群策（英文入口）](skills/swarm/SKILL.md)<br>教学示例 | Swarm<br>`swarm` | **什么时候用**　同一份稿能朝多种方向改，想请几个方向各自试一遍，最后合并重复建议。<br>**先给**　给稿面卡点、已确认的版本和不想动的段落；支持子任务时分派，单会话可逐组读。<br>**首轮产物**　按创作效果分开的结尾、取舍、引用依据和尝试范围。中文入口 `/群策` 调用同一规则。<br>**判断**　只留下会改变观众理解或孩子选择的不同结尾。着重看去掉台词后哪版仍能看出小宁的心思。 | **第一句**　请读 skills/swarm/SKILL.md。奶奶已经跨出门，小宁追出去说“我懂了”。这句太容易。请用结构、家庭喜剧和动画动作各试一个结尾，保住奶奶赴约，比较各版代价。<br><br>**第二句**　保留那个静音也看得懂的结尾，补写十秒钟。最后一件动过的道具要在前面出现过。 |
