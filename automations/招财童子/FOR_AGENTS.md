# 单集大纲任务入口

收到编剧的热点选择，直接执行 [单集开发步骤](skills/develop-outline/SKILL.md)。以同时含 `skills/`、`agents/`、`automations/` 的目录为工作包根。完整项目中这层是 `剧本系统/`，独立下载时是仓库根。旧岗位说明中以 `剧本系统/` 开头的路径均从工作包根接后半段。任务目标是编剧满意的一版单集大纲。

1. 从输入或当前对话解析选题，把所选卡片的标题、事件、来源、以小见大的切口、总纲价值原词及本集的社会主义核心价值观解读，还有编剧偏好带入本集。序号有歧义时，请编剧补对应卡片。旧卡片缺少切口或价值依据时，从所选事件和总纲补齐再交给两条创作路线。
2. 读取 [520 集项目总纲](../../docs/harness/北京一家人-创作大纲-520集.md) 的主题、人物设定、背景与边界，以编剧提供的更新版为先。在完整项目中同步读取父项目的 `docs/roadmap/北京一家人项目实战路线图.md`。独立下载时按[包内两条路线与五项审稿表](skills/develop-outline/SKILL.md)开发，并注明材料范围；编剧要求逐项对照原路线图时，请其附上原文。如运行端缺少总纲，指出缺失文件并请求提供。
3. 每次启动都从工作包根运行 `python3 tools/skill_catalog.py` 枚举所有层级的技能描述，再用 `find skills -name SKILL.md` 对照完整路径清单，补读目录工具略过的调度入口（找梗、群策、swarm）。逐项判断适用范围，描述不清就看正文。将典故、寓言与故事改编类分给 [故事新编](../../agents/故事新编.md) `story-reteller`，成熟作品拆解与机制迁移类分给 [爆款复刻](../../agents/爆款复刻.md) `reference-adapter`，结构与人物动机类分给 [剧本模型](../../agents/剧本模型.md) `story-model`，桥段、梗库、道具和套路分给 [找梗](../../agents/找梗.md) `trope-finder`，审读和修改类分给 [导演审稿](../../agents/导演审稿.md) `outline-director`。跨阶段技能可复用。主会话处理统筹、素材等适用项，保留点名限制。运行记录按路径覆盖每项，注明已用及用途、已查无命中或未用原因；同原因可分组，核对总数后对编剧只报摘要。
4. 按开发步骤用 Agent/Task 指定上述角色，为两条取材路线分别派工，可并行执行；把两路结果或材料缺口汇总后再派剧本模型。每次传入项目根绝对路径、角色所需上下文、分配的技能路径和保留项；收到结果后再推进。运行端尚未发现角色类型时可将角色文件的绝对路径交给通用子 Agent 读取执行。无派工工具时依次按角色文件执行，记录实际执行方式。招财童子负责选案、合案及返工。
5. 每个选定热点对应一集完整故事。项目总纲提供人物、背景与价值依据，两条开发路线服务于同一集。首轮交稿后进入「待编剧反馈」。收到修改意见时沿用本集记录并更新稿号，保留已认可段落。编剧明确说满意、通过或定稿，才把对应版本记为「已认可」。
