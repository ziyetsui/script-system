# 从一件小事写出它所处的时代

## 锁住本集的问题

从所选报道提取已知事实，把为康家虚构的事件另记。用一句话写出这项社会变化、公共行动或国家发展，怎样进入北京孩子今天的一件小事，迫使谁改变原有打算。从项目总纲摘出相关价值表述及章节，确定它会体现在哪个有代价的选择上。热点事实不足时用已有材料核实；未核实的细节留作虚构设定或删去。

## 分别试两条路

把同一热点卡、总纲价值依据、人物限制和各自的技能路径分别交给 [故事新编](../../../../agents/故事新编.md) 和 [爆款复刻](../../../../agents/爆款复刻.md)。前者交回典故中的选择及其当代两难，后者交回成熟作品中可核对的机制及其在康家的新用法。保留两路出处、候选和缺口，再把可用结果交剧本模型。一方材料不足时沿有依据的路线推进；两方均缺依据时先补参考材料。

点子立住后派剧本模型使用 [故事选型](../../../../skills/aiscript-story-type/SKILL.md) 比较结构，让至少两个候选在人物行动、升级方式或结局上真正不同。每案派找梗角色带一个具体卡点执行 [找梗](../../../../skills/找梗/SKILL.md)，比较不同套路各会逼出什么下一步。按该技能的发现规则查当前工作包中的梗库和技法，在运行记录里写明采纳的技能与它改变的桥段。可将一路的人物选择和另一路的喜剧机制合写，先验证二者能发生在同一条因果链上。

## 试写后再选案

为领先的不同候选各写一份短纲，比较哪版的宏大议题最能改变孩子的选择、哪版的冲突和喜剧最能演。选案后为这个热点写一篇约 500 字的完整单集故事大纲。用连贯叙事写清起承转合：孩子因这件社会事件生出什么愿望，第一次行动怎样造成新的阻碍，关键时刻怎样权衡并作出有代价的选择，结尾让谁的生活发生了什么具体变化。让观众从这一变化理解总纲对应的社会主义核心价值观。试写其中最难成立的一场，写出孩子当下要做的事、对手的反应、局面的变化和下一步后果；只把试写验证过的转折与后果写回大纲。正文按整集讲述，每个转折一两句；保留能改变局势或回收人物愿望的细节。对白、走位、机位、逐拍动作留在内部试写。故事讲清即可收尾，不为凑字数扩场。

## 审稿与返工

把当前稿和关键戏试写交导演审稿，说明拿掉热点后，哪个愿望、行动或结局会失去具体来由。普遍的道德选择可以仍然成立；检查热点是否实质连接孩子为什么要做这件事，以及结尾谁因他的选择而受益。若只剩地名或新闻开场，退回重选切口。再按项目的五项依据逐项指认稿内证据：

| 核对项 | 在稿里找什么 |
|---|---|
| 故事性 | 愿望、阻碍、升级和高潮之间有可追的因果，前面埋下的事有回收。 |
| 核心价值 | 人物为某个选择付出代价，后果体现本集对应的总纲价值。 |
| 北京特色 | 北京的公共生活、历史文化或当代发展实质影响事件。 |
| 温暖的轻喜剧 | 一个出于人物愿望的行动造成好笑的后果，同时保住人物的尊严。 |
| 逻辑自洽 | 人物动机、时空和道具前后一致；如用法宝，符合总纲的能力边界。 |

切口有问题就重选案，结构松散退给剧本模型，笑点弱退给找梗。招财童子整合后，把新稿交导演复审。保留有效段落，复查受改动影响的前后文。修到五项均有具体证据即交稿；若反复修改仍卡在同一处，交当前最佳稿和一个需要编剧判断的具体问题。

## 交付与续改

先交片名和约 500 字推荐大纲，随后以「五项复核」短段交付，每项一句，直接指认正文中的因果、代价、北京生活、喜剧机制和规则责任，最后一句说明热点对这一集的作用。再用两句话说明另一条路线与本次取舍。末尾附简短续写记录，包含选题与来源、稿号、总纲价值依据、参考作品及用到的技能、关键戏试写发现、当前状态；已在五项复核中说明的内容省略。有上版时标出本轮保留和改动的段落。默认写在任务结果中，编剧指定交稿目录时逐版保存。反馈所指向的环节就是下一轮入口。
