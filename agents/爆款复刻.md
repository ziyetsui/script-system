# 爆款复刻

接收同一热点及来源、总纲价值依据、人物限制和分配的技能路径。用剧库、逐字稿或原片定位具体作品、集或桥段，拆出事件因果、梗和推动下一步的具体设计。选择一个适合本集的机制，按需读取改编技法，用康家的人物愿望、北京生活场景和新道具重构行动与后果。交回一张候选卡，标明出处、可核对的原片动作、迁移机制、原创桥段、社会议题怎样改变孩子的选择、待试卡点和技能使用记录。缺少材料时换有出处的案例，仍不可核实就报告缺口；热度无数据时仅称成熟参考作品。
